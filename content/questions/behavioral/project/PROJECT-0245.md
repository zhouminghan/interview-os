**三、参考答案（面试标准版）**

```sql
-- 原始（倾斜）
SELECT key, SUM(value) FROM table GROUP BY key;

-- 两阶段聚合
-- 第一阶段：加随机前缀，局部聚合
SELECT key, SUM(partial_sum) AS total
FROM (
    SELECT key, SUM(value) AS partial_sum
    FROM (
        SELECT key, value, CONCAT(key, '_', FLOOR(RAND()*10)) AS salted_key
        FROM table
    ) t1
    GROUP BY salted_key, key  -- 打散聚合
) t2
GROUP BY key;  -- 第二阶段：去盐，全局聚合
```

**原理：**
1. 第一阶段：热点Key加盐打散到10个分区，各自聚合（每个分区处理1/10数据）
2. 第二阶段：去掉盐，对第一阶段结果做最终聚合（数据量已大幅减少）

**前提：** 聚合函数满足结合律（SUM/COUNT/MAX可以，MEDIAN不行）。
