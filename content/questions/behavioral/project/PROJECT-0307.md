**二、回答思路**

先给结论 → 展开核心要点（不超过3个）→ 结合项目经验 → 适用边界

**三、参考答案（面试标准版）**

```text
1. Client请求NN创建文件
2. NN检查权限/路径 → 返回可写的DataNode列表（3副本）
3. Client建立Pipeline：DN1 → DN2 → DN3
4. Client将数据按Packet发送到DN1
5. DN1写入本地并转发给DN2，DN2转发给DN3
6. 所有DN确认(ACK)后，Client继续发下一个Packet
7. 全部写完 → Client通知NN文件关闭
```

**关键设计：** Pipeline写入（链式复制），减少Client网络开销。不是Client分别写三份，而是Client只写一份，由DataNode链式复制。
