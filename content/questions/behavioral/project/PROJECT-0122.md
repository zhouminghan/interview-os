> **要点提纲**：底层原理+项目实战+持续总结 | 系统学习→入职实践→持续深化
> **来源**：京东JDY-二面-20260415 Q24

我的学习路径是：毕业后先系统学习框架底层原理（Hadoop/Spark/Hive/Flink），看文档和教程打基础。入职后在实际项目中持续深化——遇到数据倾斜就深入学 Shuffle 机制，遇到慢任务就学执行计划分析。日常也会刷 SQL 题保持手感，总结常见的数据倾斜、调优方法论。最近在学习 AI+数据工程方向，通过实际开发 Skill 来理解 LLM 的能力边界。核心方法就是"带着问题学，学完就用"，不脱离实践。
