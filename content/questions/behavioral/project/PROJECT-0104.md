# 一句话

AI 时代面试变化：AI 写简历堆术语已失效、前端转全栈、LangGraph/RAG/向量成标配、要能聊业务+开发+维护+运维的多面手。

# 要点

- AI 写简历已失效：面试官也会用 AI，一眼识破
- 前端大量转全栈，纯前端岗位收缩
- LangGraph/RAG/向量已成标配，Loop Engineering 和多 Agent 协作成标准需求
- 未来要能聊业务+开发+维护+运维的多面手
- 尖锐观点：RAG 在多数场景无用，结构化文件组织 + grep 更有效，简历写 RAG 可能暴露基础不牢
