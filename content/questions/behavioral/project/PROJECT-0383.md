# 一句话

把反问从「问福利」换成「问成事条件」：为什么招我、怎样算做好、靠什么做成，三问用来判断岗位是真需求还是接盘坑。

# 30 秒回答

来自 11-04 社招 landing 主题帖。社招和校招最大的差别是入职后要快速出结果，所以反问环节该验证的是「有没有做出成果的条件」，不是团队氛围。

# 1 分钟回答

- 为什么招我：业务扩张、补充能力，还是接替一个长期做不成的岗位？前任遇到了什么困难？——判断是不是历史遗留坑
- 怎样算做好：入职三个月、半年分别期待什么结果？能否举团队里表现好的社招员工案例？——拿不到具体标准往往意味着评价主观
- 靠什么做成：有哪些人员、预算、数据和决策权限？跨团队依赖由谁协调？——有目标没权限是典型失败组合
- 入职后对齐：第一个月和领导形成一份可回看的共识，写清优先做什么、做到什么程度、依赖谁、何时复盘
- 警惕信号：任务不断增加但评价标准不调整、要求一开始就扛跨多团队且无协调授权的大项目，都应尽早提出取舍
- 小成果破局：第一个项目选「领导认可价值 + 关键依赖可控 + 结果容易验收」的有边界成果，而不是只追大和难
- 表达姿态：用「为了把前三个月的产出做扎实，我想确认最重要的两项产出和验收标准」这类协作式措辞，不像质疑也不像谈条件
- 让贡献可见：定期同步完成结果、业务价值、需要的支持；共同成果提前明确分工，遇阻塞留下事实与推进记录

# 追问

- 面试官说「进来再看」不肯给标准，怎么接？
- 发现是接盘岗位，还要不要去？
- 前三个月怎么选第一个项目？
