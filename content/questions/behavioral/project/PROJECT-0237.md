**三、参考答案（面试标准版）**

| | Execution Memory | Storage Memory |
|---|---|---|
| 用途 | Shuffle/Sort/Join/聚合的中间数据 | 缓存RDD/DataFrame/广播变量 |
| 生命周期 | Task执行完释放 | 可以跨Task持续存在 |
| 优先级 | 高（不会被驱逐） | 低（可被Execution借用时驱逐） |
| 不足时 | Spill到磁盘 | 驱逐LRU缓存 |

**实际影响：** 如果cache了太多数据占满Storage，Execution计算时会强制驱逐缓存来获取计算内存。所以不要盲目cache。

**七、记忆版（15秒压缩）**

> Execution=计算内存(Shuffle/Sort)，优先级高。Storage=缓存内存(RDD/广播)，可被驱逐。不要盲目cache占满Storage。
