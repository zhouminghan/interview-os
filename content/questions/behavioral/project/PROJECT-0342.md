**JDK 8的HashMap：数组 + 链表 + 红黑树**

```text
数组(Node[])
├── index 0: null
├── index 1: Node → Node → Node（链表，≤8个）
├── index 2: TreeNode（红黑树，>8个）
├── ...
└── index 15: Node
```

**核心机制：**
1. **Hash定位**：`hash(key) & (n-1)` 确定数组下标
2. **冲突解决**：同一下标 → 链表存储
3. **链表→树**：链表长度>8 → 转红黑树（查询从O(n)变O(logn)）
4. **扩容**：负载因子>0.75 → 数组翻倍(resize) → 重新Hash分配

**为什么数组长度是2的幂？** `hash & (n-1)` 等价于 `hash % n`，位运算比取模快。

**线程安全？** HashMap不安全，多线程用ConcurrentHashMap。
