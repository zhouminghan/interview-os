**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：
- 你有没有成体系的方法论，不是零散的点子
- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

> 控制在2分钟

指标体系设计三层结构：

**第一层：原子指标。**
- 不可拆分的基础度量（如：曝光次数、点击次数、用户数）
- 有唯一的计算逻辑

**第二层：派生指标 = 原子指标 + 修饰词 + 时间粒度。**
```text
原子指标：曝光次数
修饰词：频道类型=游戏
时间粒度：日
→ 派生指标：游戏频道日曝光次数
```

**第三层：复合指标 = 指标之间的运算。**
```text
点击率 = 点击次数 / 曝光次数
人均互动次数 = 互动总次数 / 活跃用户数
```

**管理原则：**
- 每个指标有唯一负责人
- 每个指标有唯一计算逻辑（不允许两种算法并存）
- 指标字典公开透明，任何人可查

**四、技术知识补充**

**项目结合点：** 回答时务必结合QQ频道实际场景，体现"不是背八股，是真做过"的信号。

**五、追问预判**

1. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

2. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。

3. **追问：这个方案的边界/不适用场景是什么？**
   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 只背分层定义不说为什么 → ✅ 每层说清楚解决什么问题
- ❌ 照搬电商方案不区分业务 → ✅ 强调社交业务的特殊性（维度变化快）
- ❌ 不提治理 → ✅ 4年经验必须体现架构+治理双视角

**七、记忆版（20秒压缩）**

> 三层：原子指标（不可拆分的度量）→ 派生指标（原子+修饰词+时间粒度）→ 复合指标（指标间运算）。每个指标唯一负责人+唯一计算逻辑。
