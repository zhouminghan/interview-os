**一、面试官真正想考什么？**

不是让你背定义，考的是**原理理解和决策判断**：
- 你是否理解底层原理，不只是"因为教程说要这样"
- 你能否说清楚选择背后的权衡
- 你有没有对比过替代方案

**二、回答思路**

先给核心原因（一句话）→ 展开2-3个具体原因 → 对比如果不这样做会怎样 → 结合项目实证

**三、参考答案（面试标准版）**

五个核心原因：

1. **列式存储** — 只读需要的列，IO减少90%+
2. **向量化执行** — 批量处理（SIMD指令），不是逐行处理
3. **常驻进程** — 无Job启动开销（Hive每次要申请Container）
4. **本地SSD** — 数据在本地磁盘，不走网络（Hive读HDFS要网络）
5. **MPP并行** — 所有节点同时计算，查询自动分布式执行

**额外优化：**
- 智能索引（前缀索引/Bloom Filter/ZoneMap）
- 物化视图（预计算聚合结果）
- Pipeline执行（算子间流式传递，不落盘）

**六、常见错误/踩坑提醒**
