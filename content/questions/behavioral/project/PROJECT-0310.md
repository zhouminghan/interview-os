**一、面试官真正想考什么？**

不是让你背定义，考的是**概念理解深度和表达能力**：
- 你能否一句话抓住本质，不是背一段定义
- 你能否由浅入深地讲清楚
- 你有没有真实使用/落地的经验

**二、回答思路**

一句话定义本质 → 核心机制/原理展开 → 结合项目说落地场景 → 补充适用边界

**三、参考答案（面试标准版）**

DataNode = HDFS的"仓库工人"：
1. 存储实际数据Block
2. 处理Client的读写请求
3. 定期向NN发送心跳（证明活着）
4. 定期向NN汇报Block列表（帮NN维护映射）

**故障处理：** DN挂了 → NN检测到心跳超时 → 将该DN上的Block从其他副本复制到新DN → 保持3副本。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。

   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 背诵原理不联系实际 → ✅ 说清楚这个原理在你日常工作中哪里用到
- ❌ 只知道用不知道为什么 → ✅ 理解原理才能在出问题时快速定位
- ❌ 把Hadoop等同于MapReduce → ✅ Hadoop生态包括HDFS/YARN/MR，现在主要用HDFS+YARN
