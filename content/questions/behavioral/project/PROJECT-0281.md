**三、参考答案（面试标准版）**

三层处理：

1. **Watermark容忍**：设置合理的延迟容忍（如3秒），大部分乱序在此范围内
2. **Allowed Lateness**：窗口触发后仍接受迟到数据（触发增量更新）
3. **Side Output**：超出容忍范围的极端迟到数据，输出到侧流单独处理

```java
.window(TumblingEventTimeWindows.of(Time.minutes(5)))
.allowedLateness(Time.minutes(1))  // 窗口触发后还等1分钟
.sideOutputLateData(lateTag)        // 超过容忍的走侧流
```
