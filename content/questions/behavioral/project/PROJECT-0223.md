**一、面试官真正想考什么？**

**二、回答思路**

**三、参考答案（面试标准版）**

> 控制在1分钟

**三种发现方式：**

1. **Spark UI观察：** Stage详情页 → Task列表 → 看Duration分布。如果最慢Task是中位数的10倍以上 → 倾斜。

2. **数据预分析：**
```sql
SELECT join_key, COUNT(*) AS cnt
FROM table
GROUP BY join_key
ORDER BY cnt DESC
LIMIT 20;
```
看头部Key是否数据量异常大。

3. **Shuffle指标：** Shuffle Read Size分布不均（某些Task读取数据量远大于其他）。
