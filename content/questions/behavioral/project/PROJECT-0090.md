# 一句话

反问要分对象：问业务领导问痛点/期待，问 HR 问发展/福利/流程，别问能搜到的和 HR 该答的。

# 要点

- 问业务领导：前三个月重点解决什么、做得好和一般的区别、团队最大挑战
- 问 HR：晋升机制、团队氛围、后续流程几轮
- 别问：部门多少人（可自查）、上来就问管饭几点下班（放最后委婉问）
