**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：
- 你有没有成体系的方法论，不是零散的点子
- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

以"运营问：昨天各频道DAU是多少"为例：

```text
1. Agent理解意图："查询昨天各频道的DAU"
2. 查Knowledge Base → 找到DAU定义和对应的DWS表
3. 根据Skill模板 → 生成SQL
4. 调用MCP Tool → 执行SQL获取结果
5. 格式化输出 → 返回给运营
```

更复杂场景（数据回溯）：
```text
1. 理解："表X昨天数据有问题，需要回溯"
2. 调用血缘API → 获取上游依赖
3. 检查上游分区就绪状态
4. 生成回溯SQL（INSERT OVERWRITE）
5. 提交执行 → 等待完成
6. 验证数据正确性 → 返回报告
```

**四、技术知识补充**

**项目结合点：** 回答时务必结合QQ频道实际场景，体现"不是背八股，是真做过"的信号。

**五、追问预判**

1. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

2. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。

3. **追问：这个方案的边界/不适用场景是什么？**
   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 说"我们用AI替代了开发" → ✅ AI辅助执行，人负责决策和质量
- ❌ 把自己定位为"AI算法工程师" → ✅ 准确定位Knowledge Engineer
- ❌ 只讲技术概念不讲业务痛点 → ✅ 先说业务痛点，再说AI怎么解决

**七、记忆版（15秒压缩）**

> Agent流程：理解意图→查知识库→生成方案→调工具执行→检查结果→返回。每步都有对应的Knowledge/Skill/MCP支撑。
