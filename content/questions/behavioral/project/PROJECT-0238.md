**三、参考答案（面试标准版）**

**Spill = 内存不够时把数据写到磁盘。**

触发条件：
1. Execution Memory不足以容纳Shuffle/Sort的中间数据
2. 已经借用了Storage Memory的空闲部分仍然不够
3. 此时将部分数据溢写(Spill)到磁盘

**影响：** Spill会严重影响性能（磁盘IO远慢于内存）。频繁Spill说明内存不够。

**如何判断：** Spark UI → Stage → Task详情 → "Spill (Memory)" 和 "Spill (Disk)" 列有值。

**如何优化：**
- 增加Executor内存
- 增加shuffle分区数（减少单Task处理数据量）
- 减少Shuffle数据量（Map端预聚合/提前过滤）
