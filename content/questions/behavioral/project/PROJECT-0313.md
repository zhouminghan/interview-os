**三、参考答案（面试标准版）**

**核心问题：NameNode内存压力。**

每个文件/Block/目录在NN内存中占约150字节。
- 1亿个小文件 → NN需要~15GB内存仅存元数据
- 同样数据量如果合并成大文件 → 元数据量减少100-1000倍

**其他影响：**
1. Map Task过多：每个小文件至少启动一个Map Task → 调度开销大
2. 读取效率低：大量随机IO（每次Seek一个文件）
3. 存储浪费：每个Block不足128MB也占一个Block的元数据
