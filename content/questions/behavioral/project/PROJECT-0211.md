**三、参考答案（面试标准版）**

> 控制在1分钟

**本质原因：Join需要相同Key的数据在同一个节点上才能匹配。**

如果两张表的数据按不同规则分布在不同节点上，要做Join就必须把相同Key的数据"搬运"到同一个节点——这个搬运过程就是Shuffle。

```text
表A数据分布：Node1(key=1,2,3) Node2(key=4,5,6)
表B数据分布：Node1(key=2,4,6) Node2(key=1,3,5)

要Join key=1 → A在Node1，B在Node2 → 必须移动数据 → Shuffle
```

**如何避免Shuffle：**
- Broadcast Join（小表广播到所有节点，大表不动）
- Colocate Join（两表分桶策略相同，数据已经本地化）
