# 一句话

HR 问你薪资不是为压价，是为在预算和内部公平前提下把你招进来；回答给区间 + 看 total package，别只报一个裸月薪。

# 要点

- HR 三个目标：offer 有竞争力、符合岗位预算、平衡内部公平（新老倒挂）
- 隐藏因素：业务负责人多想要你，决定 HR 承受多大压力
- 给区间而非单点，报总包（base + 奖金 + 股票 + 补贴）
- 反问：薪资结构、涨薪机制、试用期怎么发
