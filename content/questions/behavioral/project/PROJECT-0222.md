**三、参考答案（面试标准版）**

> 控制在2分钟

Window函数执行流程：
```text
1. 按PARTITION BY字段Shuffle（相同分区数据到同一节点）
2. 按ORDER BY字段排序
3. 对每个分区内的有序数据，按窗口框架(Frame)计算
```

**关键点：**
- Window函数**一定产生Shuffle**（因为需要按PARTITION BY重分布）
- 多个Window函数如果PARTITION BY和ORDER BY相同，可以复用同一次Shuffle
- Window函数不减少行数（区别于GROUP BY）

**优化建议：**
- 多个窗口函数尽量用相同的PARTITION BY + ORDER BY
- 如果只需要TopN，用ROW_NUMBER() + WHERE rn <= N比全排序高效
- PARTITION BY字段选择高基数字段减少单分区数据量
