**三、参考答案（面试标准版）**

Reduce阶段 = 对相同Key的数据做**聚合/汇总**。

```
输入：(key, [value1, value2, value3, ...])  // 同一Key的所有Value
Reduce函数：聚合 → 输出最终结果
输出：(word, 总次数) 或 (user_id, 日活跃指标)
```

**核心特点：** 需要等待所有Map完成（因为要收集同Key数据），是全局操作。
