**三、参考答案（面试标准版）**

**Combiner = Map端的局部Reduce。** 在数据Spill到磁盘前或发送到Reduce前，先在Map端做一次局部聚合。

```text
无Combiner: Map输出 (a,1)(a,1)(a,1) → 全部传到Reduce
有Combiner: Map输出 (a,1)(a,1)(a,1) → Combine为(a,3) → 传到Reduce
```

**效果：** 减少Shuffle网络传输数据量。
**前提：** Reduce函数满足交换律和结合律（SUM/MAX/COUNT可以，平均值/中位数不行）。
