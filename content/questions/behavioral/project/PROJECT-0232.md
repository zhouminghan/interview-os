**三、参考答案（面试标准版）**

> 控制在2分钟

**Shuffle = 数据按Key重新分布到不同节点的过程。**

```text
Map端（Write阶段）：
  每个MapTask按Key Hash → 写到本地磁盘分区文件

Reduce端（Read阶段）：
  每个ReduceTask从所有Map节点拉取属于自己的分区数据
```

**Shuffle的代价：**
- 磁盘IO（Map端写本地文件）
- 网络IO（Reduce端跨节点拉取数据）
- 内存（排序/合并用到内存缓冲区）

**Spark Shuffle演进：**
- Hash Shuffle（早期）→ 文件数 = M × R，太多小文件
- Sort Shuffle（当前默认）→ 每个Map Task只输出一个文件 + 索引
