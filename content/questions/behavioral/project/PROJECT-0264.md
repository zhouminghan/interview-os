**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：
- 你有没有成体系的方法论，不是零散的点子
- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

三种实现方式：

1. **SQL解析**（最常用）：解析ETL SQL的AST，提取输入表和输出表的关系
2. **调度系统**：从任务依赖关系中推导（任务A产出表X，任务B依赖表X → 表级血缘）
3. **埋点采集**：在数据读写时记录源表和目标表

**SQL解析方案（主流）：**
```text
INSERT INTO tableB SELECT a.col1, b.col2 FROM tableA a JOIN tableC b ...
→ 解析得到：tableA → tableB, tableC → tableB
→ 字段级：tableA.col1 → tableB.col1
```

**工具：** Hive Lineage（内置）、Atlas、自研解析器
