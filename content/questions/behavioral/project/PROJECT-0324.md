**一、面试官真正想考什么？**

不是让你背定义，考的是**概念理解深度和表达能力**：
- 你能否一句话抓住本质，不是背一段定义
- 你能否由浅入深地讲清楚
- 你有没有真实使用/落地的经验

**二、回答思路**

一句话定义本质 → 核心机制/原理展开 → 结合项目说落地场景 → 补充适用边界

**三、参考答案（面试标准版）**

```text
Client → FE（Frontend：解析/优化/调度）
           ↓
         BE（Backend：存储+计算）
         BE1 | BE2 | BE3 | ...
```

**两类节点：**
- **FE**：接收SQL请求、解析优化、生成执行计划、分发到BE
- **BE**：存储数据（列式存储+副本）+ 执行计算

**FE高可用：** Leader + Follower + Observer（Raft协议选主）
**BE水平扩展：** 加BE节点 → 数据自动Rebalance

**表模型：** 明细模型(Duplicate) / 聚合模型(Aggregate) / 更新模型(Unique)

**四、技术知识补充**

本题涉及的核心技术点（面试中可能被深挖）：
- **FE**：理解其原理和适用场景，不要只记结论
- **BE**：理解其原理和适用场景，不要只记结论

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。
