**一、面试官真正想考什么？**

不是让你背定义，考的是**概念理解深度和表达能力**：
- 你能否一句话抓住本质，不是背一段定义
- 你能否由浅入深地讲清楚
- 你有没有真实使用/落地的经验

**二、回答思路**

一句话定义本质 → 核心机制/原理展开 → 结合项目说落地场景 → 补充适用边界

**三、参考答案（面试标准版）**

NameNode = HDFS的"目录管理员"：
1. 管理文件系统命名空间（目录树/文件名/权限）
2. 维护文件→Block映射
3. 维护Block→DataNode映射（根据DN心跳动态更新）
4. 处理Client的文件操作请求

**数据存储：** 元数据存内存（快速查询）+ FsImage/EditLog持久化到磁盘。

**单点风险：** NN挂了整个HDFS不可用 → 需要HA方案。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。

**五、追问预判**

1. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

2. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。

3. **追问：这个方案的边界/不适用场景是什么？**
   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 背诵原理不联系实际 → ✅ 说清楚这个原理在你日常工作中哪里用到
- ❌ 只知道用不知道为什么 → ✅ 理解原理才能在出问题时快速定位
- ❌ 把Hadoop等同于MapReduce → ✅ Hadoop生态包括HDFS/YARN/MR，现在主要用HDFS+YARN

**七、记忆版（10秒压缩）**

> NN=目录管理员。管文件树+Block映射+DN映射。元数据在内存(快)+磁盘(持久化)。单点需HA。
