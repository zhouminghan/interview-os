**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：
- 你有没有成体系的方法论，不是零散的点子
- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

三阶段培养：

**第一阶段（1-2周）：熟悉环境**
- 提供文档（数仓架构/命名规范/开发流程/常见问题FAQ）
- 安排Mentor一对一
- 布置入门任务（读懂已有表的逻辑/跑通一个简单ETL）

**第二阶段（1-2月）：独立开发**
- 从简单需求开始，逐步增加复杂度
- Code Review必须，每次Review给出改进建议
- 鼓励问问题，建立"没有愚蠢问题"的氛围

**第三阶段（3-6月）：承担责任**
- 独立负责一个主题域或模块
- 参与值班和故障处理（增强线上意识）
- 参与技术分享（教是最好的学）

**核心理念：** 知识库沉淀（不靠口口相传）+ 渐进式放手（不是扔进去自生自灭）。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。

**五、追问预判**

1. **追问：如何判断一个需求应该放在DWD还是DWS？→ 看复用性：多个下游都用放DWS，单一场景放ADS。**

2. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

3. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。


**六、常见错误/踩坑提醒**

- ❌ 只讲技术不讲软技能 → ✅ S6级别需要架构能力+推动能力+方法论
- ❌ 不展现成长路径 → ✅ 从执行者→设计者→推动者的转变
- ❌ 对AI的态度极端(替代/无用) → ✅ 会用AI的人替代不会用的人

**七、记忆版（15秒压缩）**

> 三阶段：熟悉(文档+Mentor+入门任务)→独立开发(简单→复杂+CodeReview)→承担责任(独立负责+值班+分享)。关键：知识文档化+渐进放手。
