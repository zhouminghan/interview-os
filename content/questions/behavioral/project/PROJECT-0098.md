# 一句话

先接住拿书面 offer（口头无法律效力），再问清薪资构成、绩效、试用期、晋升等 7 件事。

# 要点

- 先回「感谢认可，书面 offer 什么时候发」，拿到书面保底
- 问：薪资构成（base/绩效/提成/补贴、税前税后、几薪）
- 问：绩效标准、扣钱吗、拿满比例
- 问：试用期薪资、转正标准、晋升机制、到岗时间
- 口头 offer 没有法律效力，拿到书面才有主动权
