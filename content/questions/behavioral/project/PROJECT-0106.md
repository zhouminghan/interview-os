# 一句话

每天录 3 分钟短视频回看，检查表情、眼神、流畅度，记下口头禅和卡顿逐个改，用「视频这面最诚实的镜子」纠正表达坏习惯。

# 要点

- 操作：每天录 3 分钟短视频，讲思考或见闻
- 回看维度：表情是否自然、眼神是否坚定、说话是否流畅
- 纠错：记下口头禅、卡顿、啰嗦，下次刻意改
- 价值：视频回放暴露的自我形象与主观感受的差距，是快速改掉表达毛病的抓手
- 侧重非语言表达（表情/眼神/流畅），区别于写作/口述复盘侧重内容逻辑
