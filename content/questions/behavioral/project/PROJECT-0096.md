# 一句话

大厂黑话要先懂才能进对话：厂名昵称、JD/HC/Base/Package/PM、+1/+2、owner、OKR、one-one 等。

# 要点

- 厂名：宇宙厂（字节）、鹅厂（腾讯）、开水团（美团）、福报厂（阿里）、铁厂（快手）
- 职位：JD（岗位说明）、HC（名额）、Base（地点）、Package（总包）、PM（产品）
- 职场：+1/+2（上级/上上级）、mt（带教）、ld（leader）、hrbp、owner（背锅人）、OKR、one-one（一对一）、DDL
