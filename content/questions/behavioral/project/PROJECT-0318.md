**三、参考答案（面试标准版）**

```text
Map端（Write）：
  map()输出 → 内存缓冲区(环形Buffer, 100MB)
    → 缓冲区80%满时Spill到磁盘（Spill前：分区+排序+可选Combine）
    → 多个Spill文件Merge成一个最终文件（每个Partition一段）

Reduce端（Read）：
  从所有Map节点拉取对应Partition数据(HTTP)
    → 内存/磁盘Merge排序
    → 交给reduce()函数处理
```

**关键细节：**
- 环形缓冲区避免频繁Spill（攒够80%再写）
- Spill时做排序+分区（为Reduce拉取做准备）
- Combiner可在Spill前局部聚合（减少Spill和网络传输数据量）
