# 一句话

高频题就那几道：自我介绍、离职原因、职业规划、优缺点、薪资期望；用「数据说话 + 贴岗位」的结构化话术。

# 要点

- 自我介绍：1-3 分钟，背景 + 经历 + 技能 + 匹配点，别背简历
- 为什么选我们：行业 + 业务特色 + 能力匹配
- 缺点：真实非致命 + 改进动作
- 职业规划：短期深耕 + 中长期扩展，别空谈当负责人
- 无相关经验：可迁移能力 + 用做项目的方式补课
