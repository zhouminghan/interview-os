# 一句话

诚实说明边界 + 把已有数据工作迁移过去 + 补一个小原型 + 收束到「我能贡献什么」。

# 30 秒回答

这题考的是诚实和迁移能力。硬编造项目一定会被追问穿，正确做法是承认边界，然后指出数据开发和 Agent 落地的强关联：Agent 落地的瓶颈往往不在模型而在数据工程（schema 乱、注释缺、口径糊涂），这恰恰是数据人的主场。再花两个周末做个小原型，就有了可讲的东西。

# 1 分钟回答

- 诚实说明边界：讲清楚哪些是自己做的、哪些只是用过，不要硬编造
- 迁移已有经验：元数据治理、口径梳理、质检规则、SQL 优化，都是 Agent 落地的地基
- 补一个小原型：两个周末做一个最小可用的问数或巡检 Agent，讲得出设计取舍
- 收束到贡献：我能为团队的 AI 落地解决什么具体问题
- 避免：把「用过 Cursor」讲成「做过 Agent 开发」
