# 一句话

被刷多半不是能力不行，是细节和态度：没提前做功课、说无关废话、没气场。

# 要点

- 提前做功课：花十分钟了解公司/行业，面试提一两句很加分
- 说岗位相关优势，别扯无关琐事
- 放大声音、眼神对视，拿出底气气场
- HR 考核入职率+留存率，不是刷 KPI，别一被挂就阴谋论
- 遇「入职先掏钱/垫钱」的垃圾公司，扭头就走
