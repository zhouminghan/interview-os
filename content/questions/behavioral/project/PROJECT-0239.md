**三、参考答案（面试标准版）**

**AQE = Adaptive Query Execution（自适应查询执行）。** Spark 3.0引入的运行时优化机制。

**核心思想：** 不在编译时固定执行计划，而是在运行时根据实际数据统计信息动态调整。

```text
传统：编译时决定执行计划（可能因为统计信息过时而次优）
AQE：每个Stage执行完后，用实际数据统计信息重新优化后续Stage
```

**开启：**
```
spark.sql.adaptive.enabled = true（Spark 3.2+默认开启）
```

**六、常见错误/踩坑提醒**

- ❌ 直接说调参数 → ✅ 先通过Spark UI定位问题类型，再针对性优化
- ❌ 不区分倾斜类型 → ✅ Join倾斜/聚合倾斜/分区不均方案不同
- ❌ 忽略全链路影响 → ✅ 优化一个环节可能影响下游（如增加分区→小文件）

**七、记忆版（15秒压缩）**

> AQE=运行时根据实际数据动态调整执行计划。不依赖可能过时的静态统计信息。Spark 3.0+引入。
