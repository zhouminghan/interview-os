# 一句话

回答「第一句就是结论」，15 秒内给结论再展开；配合朗读复盘（读问题 → 读原答 → 重说）纠正绕弯和缺结论。

# 要点

- 为什么练：讲不清不是不懂，是用复杂语言回应对方的焦虑，频道没对齐
- 方法一：朗读热身 3 分钟，把嘴打开
- 方法二：盘一道复盘题：读面试官问题 → 读自己原答 → 用标准重说
- 标准：第一句就是结论（≤15 秒），再给理由和例子
- 核心：先结论后展开，避免「绕了一大圈还没到点」
