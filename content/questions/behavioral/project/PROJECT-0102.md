# 一句话

字节简历锁定：同一时间只能走一个岗位流程，别盲投；用「田忌赛马」分冲刺岗/稳妥岗/保底岗。

# 要点

- 锁定机制：一个岗位被查看/进面试，同期其他投递暂停
- 别盲投：第三方平台 + 官网双投效果差
- 田忌赛马：上等马（冲刺岗，踮脚够）、中等马（稳妥岗，匹配）、下等马（保底岗，快速入职）
- 冲刺失利，面试经验也能复用
