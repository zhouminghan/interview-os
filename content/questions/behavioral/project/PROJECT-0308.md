**一、面试官真正想考什么？**

不是让你背定义，考的是**实操经验和问题解决能力**：
- 你是否有真实的动手经验
- 你能否讲清楚具体的做法和效果
- 你对这个问题的理解深度

**二、回答思路**

先给结论 → 展开核心要点（不超过3个）→ 结合项目经验 → 适用边界

**三、参考答案（面试标准版）**

```text
1. Client请求NN打开文件
2. NN返回文件的Block列表及每个Block的DN位置（按距离排序）
3. Client选择最近的DN读取第一个Block
4. 读完Block1 → 选择最近DN读Block2 → ... 直到读完
5. Client合并所有Block → 完整文件
```

**关键设计：** 就近读取（优先同机架/同数据中心），减少网络开销。Client直接和DN通信，NN不参与数据传输。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。
