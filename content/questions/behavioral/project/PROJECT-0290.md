**一、面试官真正想考什么？**

不是让你背定义，考的是**技术对比和选型能力**：
- 你能否准确说出核心差异（不是背表格）
- 你知道什么场景用A、什么场景用B
- 你有没有实际选型经验

**二、回答思路**

先给核心差异（一句话）→ 表格/列表对比 → 说明各自适用场景 → 结合项目选型经验

**三、参考答案（面试标准版）**

| | Prompt | Skill |
|---|---|---|
| 本质 | 一次性指令 | 可复用的流程定义 |
| 复杂度 | 简单（一句话） | 复杂（多步骤+条件+工具调用） |
| 可维护性 | 低（写完就忘） | 高（版本管理+迭代优化） |
| 触发方式 | 每次手动输入 | 自动匹配触发 |

**类比：** Prompt像口头指示，Skill像SOP手册。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。

**五、追问预判**

1. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

2. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。

3. **追问：这个方案的边界/不适用场景是什么？**
   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 说"我们用AI替代了开发" → ✅ AI辅助执行，人负责决策和质量
- ❌ 把自己定位为"AI算法工程师" → ✅ 准确定位Knowledge Engineer
- ❌ 只讲技术概念不讲业务痛点 → ✅ 先说业务痛点，再说AI怎么解决

**七、记忆版（10秒压缩）**

> Prompt=一次性口头指示。Skill=可复用的SOP流程（多步骤+工具调用+可维护）。
