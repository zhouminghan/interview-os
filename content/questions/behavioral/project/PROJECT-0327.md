**三、参考答案（面试标准版）**

因为分析场景的特点正好匹配OLAP的设计：

| 分析场景特点 | OLAP对应设计 |
|-------------|-------------|
| 只读少数列 | 列式存储（只读需要的列） |
| 聚合计算多 | 预聚合/向量化加速 |
| 实时性要求高 | 常驻进程+内存计算 |
| 查询模式多变 | 灵活索引+物化视图 |
| 数据追加为主 | 批量写入优化 |

**对比OLTP：** OLTP是行存（一次读一行所有字段），适合点查和事务。OLAP是列存（一次读一列所有行），适合聚合分析。

- ❌ 不提使用场景 → ✅ 说清楚什么场景用MPP（高并发低延迟查询）

**七、记忆版（10秒压缩）**

> 分析=读少数列+聚合+实时。OLAP=列存+向量化+常驻进程+预聚合。和OLTP(行存/点查/事务)互补。
