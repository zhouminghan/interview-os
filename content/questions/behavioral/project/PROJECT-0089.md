# 一句话

先反问差距和原因，再表态「差距不大愿综合看」，别秒答「可以」也别硬刚「不来」。

# 要点

- 反问：「和我预期差多少？是预算有限还是能力评估差异？」
- 表态：「差距不大愿意综合考虑，我看重团队/成长/项目，希望一起商量可行方案」
- 顺势问三句：薪资结构、涨薪机制、试用期与转正标准
- 别只看月薪，看成长空间、团队氛围、发展匹配
