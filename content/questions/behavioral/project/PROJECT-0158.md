# 回答框架

一句话原则：把「离开」讲成「奔向更好」，而不是「逃离现状」。

- 客观且体面：业务调整 / 团队变动 / 成长空间有限，选一个最真实的原因，不抱怨前司
- 正面动机：想接触更有挑战的项目、更匹配的技术方向
- 收尾落到目标岗位：这家公司的方向正好对得上，所以想加入

# 待补充（个人事实）

替换成自己真实的离职原因与诉求。
