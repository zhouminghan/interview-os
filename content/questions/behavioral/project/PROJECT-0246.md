**三、参考答案（面试标准版）**

**适用条件：Join一侧数据可以放进Executor内存（默认<10MB，可调大）。**

适用场景：
1. 大表 Join 小维度表（如日志Join用户等级表）
2. 过滤后一侧数据量大幅减少
3. 字典表/配置表关联

不适用场景：
- 两侧都是大表（广播不下）
- 小表也很大（>数GB，广播占用太多内存+网络）

**参数调整：**
```
spark.sql.autoBroadcastJoinThreshold = 100MB  -- 根据集群内存调大
```
