# 一句话

大厂卡涨幅基本 30%~40%，超过 40% 需硬实力；薪酬包优先级大于职级，谈薪谨慎不要乱说想法。

# 要点

- 卡涨幅每家差不多 30~40%，超 40% 要硬实力
- 研发/算法开价高，2-2 职级 range 可覆盖 90% 的人
- 非研发岗 50w 以下总包 2-1 职级随意给
- 关键节点：业务面后的初步薪酬沟通，每句话都被记录
- 薪酬 80% 由字节薪酬公式决定，BP 主要试探底线
- 挂横向大概率是竞争，不是你要价高
