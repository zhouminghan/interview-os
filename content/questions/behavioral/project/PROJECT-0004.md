# 回答框架

- 先明确产品目标用户是谁，角色是「身份」还是「画像/属性」
- 用户角色：按权限、场景、阶段区分（如访客/会员/运营/管理员）
- 画像属性：年龄、性别、偏好，用于推荐和内容差异化，但要避免敏感信息
- 设计落地：角色影响权限、流程、界面；属性影响推荐和内容
- 面试考察点：你是否想过「给谁用、不同人有什么不同需求」
