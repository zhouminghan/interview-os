# 一句话

复盘通用教训：技术细节要严谨（Spark/Flink 机制别讲错）、表达要简洁量化（别绕、给数字）、经历要有可验证闭环（基线/动作/结果/边界）。

# 要点

- 技术正确性：方向对但机制表述不严谨（Barrier/两阶段提交/加盐）会放大「高级岗」风险
- 表达：被要求「一句话」还展开、先讲通用套路再讲案例、薪资被追问不给数，都难让面试官快速识别上限
- 证据闭环：项目要有基线、个人动作、结果指标、故障边界，别用「应该/好像/反正」
- JD 匹配：必备项（实时/OLAP 引擎/语言）缺证据要主动补
- 外部因素：竞争/HC/职级/外包偏好无法验证，复盘别过度归因
