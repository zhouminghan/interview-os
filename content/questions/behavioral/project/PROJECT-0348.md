**一、面试官真正想考什么？**

不是让你背定义，考的是**原理理解和决策判断**：
- 你是否理解底层原理，不只是"因为教程说要这样"
- 你能否说清楚选择背后的权衡
- 你有没有对比过替代方案

**二、回答思路**

先给核心原因（一句话）→ 展开2-3个具体原因 → 对比如果不这样做会怎样 → 结合项目实证

**三、参考答案（面试标准版）**

选Spark的原因（结合QQ频道项目）：

1. **批处理性能好** — 内存计算+DAG优化，百亿级任务从MR小时级降到分钟级
2. **SQL生态成熟** — Spark SQL语法丰富，适合数据开发团队
3. **与Hive兼容** — 可以无缝读写Hive MetaStore
4. **AQE** — Spark 3.x的自适应优化大幅减少手动调参
5. **团队熟悉** — 团队有丰富的Spark调优经验

**为什么不选其他：**
- Flink：更适合流处理，批处理能力和生态不如Spark成熟
- Presto/Trino：适合即席查询，不适合重ETL
- MapReduce：太慢，已淘汰

**五、追问预判**

1. **追问：Spark任务OOM怎么排查？→ 看Executor GC Time/Shuffle Spill/Driver Log，定位是堆内还是堆外。**

2. **追问：Hive和Spark SQL有什么区别？→ Hive底层是MR（慢），Spark SQL底层是DAG（快），但Hive MetaStore两者共用。**

**七、记忆版（15秒压缩）**
