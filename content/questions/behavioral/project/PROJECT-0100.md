# 一句话

跳槽是有计划的自我升级：先理清离职原因和目标，再准备简历面试，全程保密别让现公司知道。

# 要点

- 前期：先想清楚离职根本原因和目标，别冲动
- 保密：在职找别被现公司发现
- 简历：STAR 法则写项目（背景/角色/动作/结果）
- 面试：社招基本聊项目，少八股，准备深度展开的点
- 收尾：礼貌交接，别踩老东家
