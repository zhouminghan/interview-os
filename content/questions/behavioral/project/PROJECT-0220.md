**三、参考答案（面试标准版）**

> 控制在1分钟

**动态分区 = INSERT时不指定具体分区值，由数据中的字段值自动确定写入哪个分区。**

```sql
-- 静态分区
INSERT INTO table PARTITION(dt='2024-01-01') SELECT ...;

-- 动态分区
SET hive.exec.dynamic.partition = true;
SET hive.exec.dynamic.partition.mode = nonstrict;
INSERT INTO table PARTITION(dt) SELECT ..., dt FROM source;
```

**原理：** Reduce阶段根据分区字段值将数据路由到不同分区目录。

**注意事项：**
- 动态分区容易产生大量小文件（长尾分区数据少）
- 建议限制最大分区数：`hive.exec.max.dynamic.partitions = 1000`
- 结合文件合并参数使用
