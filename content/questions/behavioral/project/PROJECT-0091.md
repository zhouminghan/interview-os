# 一句话

面试别太老实也别背套话，回答要具体、可量化、往岗位靠；八个高频问题都要有备。

# 要点

- 为什么想来：说行业 + 产品 + 匹配，别空泛表忠心
- 有什么想问：准备 2-3 个，别说没有
- 缺点：真实但非致命 + 强调改进，别说「太完美」
- 核心竞争力/胜任力：往岗位能力靠，用数据/成果佐证
- 专业不对口：讲可迁移能力 + 主动补课
