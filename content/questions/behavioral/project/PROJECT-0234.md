**三、参考答案（面试标准版）**

```text
Map Task执行完毕 →
  内存Buffer（排序）→ 溢出(Spill)到磁盘 → 合并(Merge)成一个有序文件 + 索引文件

Reduce Task →
  根据索引从文件的对应区间拉取自己的数据
```

**核心设计：**
- 每个Map Task只产生**一个数据文件 + 一个索引文件**（解决Hash Shuffle的小文件问题）
- 数据在文件内按Partition ID排序，索引记录每个Partition的偏移量
- Reduce端通过索引精确读取所需数据段

**对比Hash Shuffle：**
- Hash Shuffle：M个Map × R个Reduce = M×R个文件（灾难级小文件）
- Sort Shuffle：M个Map × 2 = 2M个文件（可控）
