**一、面试官真正想考什么？**

不是问分层定义，是考你能否用一句话抓住本质。

**二、回答思路**

一句话结论 → 三个核心价值 → 结合项目

**三、参考答案（面试标准版）**

> 控制在1分钟

**一句话结论：数仓分层的本质价值是隔离变化，提高复用。**

展开来说三个核心价值：

1. **隔离变化**：上游数据源格式变了、字段改了，影响范围被限制在ODS/DWD层，不会穿透到分析层。
2. **提高复用**：公共指标在DWS层只算一次，多个应用共享，不用每个需求从头算。
3. **保证一致**：指标口径统一管理，减少"同一个指标不同人算出不同数字"的问题。

**结合项目：** 在QQ频道业务中，手Q日志格式经常调整。因为有分层，格式变化只需要改ODS→DWD的清洗逻辑，DWS以上的所有报表和应用完全不受影响。如果没有分层，每次日志改动都要改所有下游SQL。

**四、技术知识补充**

没有分层时的问题（反面案例）：
```text
需求A：SELECT ... FROM 原始日志 WHERE ... GROUP BY ...
需求B：SELECT ... FROM 原始日志 WHERE ... GROUP BY ...（口径微妙不同）
需求C：SELECT ... FROM 原始日志 WHERE ... GROUP BY ...

→ 三个人写了三份SQL，指标定义各不相同
→ 日志格式一改，三份SQL全部报错
→ 某天发现A和B算出的DAU差了20%，排查3天
```

**五、追问预判**

1. **追问：分层会不会增加开发成本？** → 短期是的（多写一层ETL），但长期大幅降低维护成本和重复开发成本。

**六、常见错误/踩坑提醒**

- ❌ 「DWD是明细层，DWS是汇总层」（只说定义） → ✅ 要说**为什么**需要这样分

**七、记忆版（20秒压缩）**

> 分层 = 隔离变化 + 提高复用 + 保证一致。变化被限制在底层，公共指标只算一次，口径统一管理。
