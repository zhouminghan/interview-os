# 一句话

字节面试一面 Peer 基本功 → 二面直属 Leader 项目 → 三面部门 Leader 上限 → 交叉面拉齐 → HR 动机稳定性；避雷：真实>完美、不作弊不撒谎、结构化表达。

# 要点

- 流程：实习生 2-3 轮、社招 3-4 轮技术 + HR；一面 Peer、二面直属 Leader、三面部门 Leader、交叉面、HR 面
- 各轮重点：一基本功、二项目与思考、三能力上限与匹配、交叉拉齐标准、HR 动机稳定性
- 避雷：真实>完美、不作弊、不撒谎、结构化表达、控情绪、适度示弱
- 心态：面试天然不公平，多轮是为降主观偏差；通过≠你强，不通过≠你不优秀
