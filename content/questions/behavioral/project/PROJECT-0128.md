> **来源面经**：腾讯WXG-数据工程实习一面-20260513 Q1

WXG/字节这类大厂一面常见「算法 + SQL + 智力题」组合手撕，难度中等但临场要求高，应对策略：

**算法部分**——大数据岗算法题不会特别难，常见就是字符串处理、数组双指针、简单的哈希计数、扫描线（区间合并/同时在线峰值）这几类。
- **先和面试官确认输入输出和边界**——"数组会不会为空"、"重复值怎么处理"、"返回 -1 还是抛异常"；
- 写完先口述思路再跑测试用例，时间复杂度主动报出来；
- 优先暴力解 + 优化路径 → 让面试官看到你的思考层次。

**SQL 手撕**——大数据岗的重点，常考连续登录、TopN、留存率、漏斗、扫描线求同时在线峰值。
- **优先窗口函数**：`ROW_NUMBER` / `LAG` / `SUM OVER` 三件套基本能解决 80% 的题；
- 写完一定要主动讲一遍「这里 PARTITION BY 是按什么分组、ORDER BY 是按什么排序、为什么这样取」；
- 复杂题先写 CTE 分步，比一段嵌套 SQL 更易读、面试官更容易看到思路。

**智力题**——WXG/字节喜欢出（称重找次品、灯泡开关、井盖为什么是圆的）。
- **不要立刻报答案**——先复述题目确认理解，然后大声讲推理过程；
- **思路调整也要讲**——让面试官看到逻辑链而不是结果；
- 真不会就诚实说「我先讲一下我能想到的思路」，面试官看的是思考过程不是答案。

**通用原则**：
- 写代码时**保持出声**，闷头乱写最忌讳；
- 卡壳了直接说"我想一下"或"这里我有两种思路"，比硬写更专业；
- 写完主动跑测试用例，包括正常用例 + 边界用例（空、单元素、重复元素）。

> 💡 **专家补充**：
> - **大厂手撕的难度定位是"中等偏基础"**——不是 LeetCode hard，重点考察代码规范性、边界处理、思路清晰度。能写完 + 能讲清楚比能写难题但讲不清楚更得分
> - **"算法 + SQL + 智力题"组合考察的是不同思维范式下的反应能力**——建议手撕前先问面试官"先做哪个"以争取调整心态的时间
> - **手撕的隐藏分在"沟通"上**：面试官最看重的不是答案，是候选人遇到问题时的思考过程、卡壳时的应变能力、和面试官的沟通节奏。会写题但不会沟通的候选人评分往往不高
