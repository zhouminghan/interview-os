# 一句话

三条：及时汇报（做一点就反馈方向）、养成复盘习惯（沉淀个人 SOP）、向上管理（定期对齐目标防跑偏）。

# 要点

- 及时汇报：别等催，做一点就反馈，确认方向是否对
- 复盘：项目后 15-30 分钟复盘，沉淀经验/优化流程成 SOP
- 向上管理：每两周/每月对齐目标，问「最近重点对吗，有没有要调整的」
- 长期价值：转正/面试时这些沉淀能发挥大作用
