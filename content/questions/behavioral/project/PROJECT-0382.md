# 一句话

用「组织优化」中性表述带过，立刻把落点转到技术规划和求职诉求上，不吐槽、不提绩效、不说「辞退」。

# 30 秒回答

这是社招行为面里最容易翻车的一题（11-03 数仓岗帖子专门拆过）。面试官真正想确认的是：你有没有风险、动机是不是稳定、是不是被淘汰的。所以答案要短、要中性、要立刻往前看，别在原因上纠缠。

# 1 分钟回答

- 主推版本：原业务线战略收缩、组织进行人员优化，我被动离开；我本身一直深耕数仓与实时计算，希望找到业务稳定、能持续落地数据平台与 Agent 相关场景的团队，长期做技术沉淀
- 简短版本：之前业务调整、团队缩编优化，因此出来看新机会，想继续在数据开发方向深耕
- 用词：统一用「组织优化 / 人员缩编 / 业务调整」，不主动使用「辞退、开除」
- 避雷一：不吐槽领导、公司，不提绩效、矛盾、仲裁
- 避雷二：不解释过多细节，越描越像有问题；讲完原因立刻转到下一步
- 避雷三：不把「被动」当重点，把「我要什么」当重点
- 落点建议：结合目标岗位讲技术方向（如数据平台 + Agent 场景），让动机具体可信
