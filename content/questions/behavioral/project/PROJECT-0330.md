**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：

- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

| 场景 | 选择 | 原因 |
|------|------|------|
| PB级离线ETL | 湖仓(Spark+Iceberg) | 大规模批处理能力强 |
| 交互式查询/看板 | MPP(Doris/StarRocks) | 秒级响应 |
| 批流统一存储 | 湖仓(Iceberg/Hudi) | 支持流式写入+ACID |
| 明细数据即席分析 | 湖仓+外表查询 | 数据量太大MPP放不下 |
| 聚合数据快速查询 | MPP | 预聚合+列存极快 |

**最佳实践（我们的做法）：**
```text
湖仓（Spark+Iceberg）做离线加工
    ↓ 结果数据导入
MPP（Doris/StarRocks）做查询服务
```

**不是二选一，是组合使用。** 湖仓负责"加工"，MPP负责"服务"。
