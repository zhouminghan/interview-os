**一、面试官真正想考什么？**

不是让你背定义，考的是**方法论和实操能力**：
- 你有没有成体系的方法论，不是零散的点子
- 你能否结合真实项目说明具体做法
- 你对方案的边界和取舍是否清晰

**二、回答思路**

先给方法论框架 → 分步展开核心要点 → 结合项目举例 → 补充边界和注意事项

**三、参考答案（面试标准版）**

**原则：不是说"不做"，而是引导到合理方案。**

四步处理：

1. **理解真实诉求** — 需求背后要解决什么问题？（可能有更好的方案）
2. **评估影响** — 这个需求的成本/收益是什么？（量化给业务方看）
3. **提供替代方案** — "你的目标可以用方案B实现，成本更低/更快/更好"
4. **升级决策** — 如果分歧大，带着评估结果找共同上级决策

**典型场景：**
- 业务方要"实时看数据" → 评估是否真需要实时？T+1看板+关键指标分钟级是否满足？
- 业务方要"建一张新表" → 是否已有公共表能满足？引导复用。
- 业务方要"改指标口径" → 评估影响范围，走变更流程。

**四、技术知识补充**

**项目结合点：** 回答时主动关联QQ频道的实际场景，增强可信度。

**五、追问预判**

1. **追问：这个方案在你的项目中是怎么落地的？**
   → 结合QQ频道百亿级日志的实际场景，说明具体做法和效果。

2. **追问：如果重新设计，你会改什么？**
   → 体现反思能力：讲一个当初的取舍，现在回头看可以优化的点。

3. **追问：这个方案的边界/不适用场景是什么？**
   → 任何方案都有适用范围，说清楚什么时候不应该用这个方案。


**六、常见错误/踩坑提醒**

- ❌ 只讲技术不讲软技能 → ✅ S6级别需要架构能力+推动能力+方法论
- ❌ 不展现成长路径 → ✅ 从执行者→设计者→推动者的转变
- ❌ 对AI的态度极端(替代/无用) → ✅ 会用AI的人替代不会用的人

**七、记忆版（15秒压缩）**

> 不说"不做"，引导到合理方案。四步：理解真实诉求→量化评估→提供替代方案→必要时升级决策。
