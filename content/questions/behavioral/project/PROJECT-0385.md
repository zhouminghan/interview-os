# 一句话

归因自己、面向未来、不吐槽老东家、对齐目标岗位方向；按成长 / 业务匹配 / 架构挑战准备三套话术，现场挑一套贴 JD 的用。

# 30 秒回答

整合 11-02 数仓面试图片帖（3 套稳妥答案）与 08-15「你为什么离职」拆解。库里已有 `PROJECT-0158/0371/0080/0110` 的通用版和 `PROJECT-0382` 的「被优化」版，这一张专补**数开 / 数据 Agent 方向**的话术对齐。

# 1 分钟回答

- 核心原则：归因自己（我方向想变）、面向未来（我要做什么）、不吐槽（不提加班/领导/同事/薪资/技术栈烂）、对齐岗位（实时数仓、湖仓一体、数据 Agent、NL2SQL）
- 版本 1 成长导向（一面/二面通用，最推荐）：现有业务链路已稳定、迭代偏维护，新技术落地机会不多；想深耕实时数仓、湖仓一体、数据开发 Agent，到更大流量和复杂场景做技术落地
- 版本 2 业务方向匹配（面有大厂 AI 数据 / Agent 业务的团队）：团队业务重心与长期方向错开，后续很少有机会做 NL2SQL、数据 Agent；了解到贵团队在数据智能、Agent 数仓有落地，希望把数仓能力结合 AI 做更多实践
- 版本 3 架构挑战导向（P7 / 资深）：原项目架构定型，更多是维稳和指标迭代，缺架构重构与链路升级机会；希望参与大规模数据链路改造、数据平台智能化建设
- 面试官脑子里的四个风险判断：问题是不是出在你身上（绩效/人际）；动机健康吗（成长 vs 逃离/纯为钱）；同样原因会不会让你离开我们（说上家加班多，而他们也加班就自筛了）；你怎么谈论前雇主（今天骂前司，明天骂他们，这条最致命）
- 三种翻车姿势：实话实说型（领导坑/天天加班/甩锅，句句可能是真的但听者是另一层意思）、过于实诚型（只说钱少了，会被想「别人多给两千你是不是又走」）、敷衍型（想换个环境，等于没说还引来更深追问）
- 避坑清单：加班多、领导不好、同事难配合、薪资低；老项目太烂、技术栈老旧、不想做；和团队理念不合、内部内卷
- 万能落点模板：在上家完成了 X（具体成果），也感谢那段经历；但在 Y 方向上当前平台空间有限；贵司这个岗位正好在 Y 上有空间，这是我看重的
