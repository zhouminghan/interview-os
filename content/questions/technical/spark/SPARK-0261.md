question: Spark SQL 的作用是什么？
difficulty: 0
topic: []
source_type: knowledge
---

Spark SQL 用于运行 SQL 查询。可以将 Spark SQL 与 Spark 中的 SQL 以及 Dataset API 一起使用。在执行期间，Spark SQL 对 SQL 和 Dataset API 使用相同的计算引擎。通过 Spark SQL 可以获取更多关于数据结构以及正在执行的计算的信息。还可以使用 Spark SQL 从现有 Hive 安装中读取数据。Spark SQL 也可以通过 JDBC/ODBC API 和命令行访问。
