question: 什么是 Spark Streaming？
difficulty: 0
topic: []
source_type: knowledge
---

**Spark Streaming** 是 Spark 中用于处理大量实时数据流的非常流行的特性。Spark Streaming 使用 Spark API 创建高度可扩展、高吞吐量和容错的实时数据流处理系统。Spark Streaming 支持从 Kafka、Kinesis、Flume 等流行来源摄取数据，可以对通过 Spark 流处理的数据应用 map、reduce、join 等流行函数，处理后的数据可以写入文件系统、数据库或实时仪表盘。
