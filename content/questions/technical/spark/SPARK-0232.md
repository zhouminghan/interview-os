# 一句话

提供 SQL 服务的组件，让外部用 SQL 查 Spark。

# 参考回答

Spark SQL Server 泛指用 Spark 提供 SQL 服务的组件，最常见的是 Thrift Server，通过 JDBC 提供 SQL 查询入口。
