# 一句话

Spark SQL 用 SQL 查结构化数据，带 Catalyst 优化。

# 参考回答

Spark SQL 是 Spark 的结构化查询模块，能直接写 SQL 或 DataFrame API，背后有 Catalyst 优化器。特点是统一、快、兼容 Hive。
