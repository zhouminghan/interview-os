question: Apache Spark 的不同部署模式？
difficulty: 0
topic: []

Apache Spark 的一些常见部署模式如下：
- **Amazon EC2**：可以使用 AWS 云产品 Elastic Compute Cloud (EC2) 部署和运行 Spark 集群。
- **Mesos**：可以使用 Apache Mesos 在私有集群中部署 Spark 应用。
- **YARN**：还可以在 Apache YARN（Hadoop 下一代）上部署 Spark。
- **Standalone（独立模式）**：可以手动启动 Spark 的独立模式，手动启动独立集群。
