**难度**：⭐⭐⭐⭐

**业务场景**：SHEIN 全球多仓库，订单产生时需自动选择最优出货仓。

**题目**：选择**有库存**（库存 ≥ 订购量）的仓库中**距离用户最近**的仓库。同时计算预计送达时间 = 距离 × 1.5 小时 + 拣货 1 小时。

### 表结构

**`orders`** — 订单表

| 字段 | 类型 | 说明 |
|---|---|---|
| order_id | bigint | 订单 ID |
| sku_id | string | SKU |
| qty | int | 购买数量 |
| country | string | 收货国家 |

**`warehouse_stock`** — 仓库库存

| 字段 | 类型 | 说明 |
|---|---|---|
| warehouse | string | 仓库编码 |
| sku_id | string | SKU |
| stock | int | 库存量 |

**`warehouse_distance`** — 仓库距离

| 字段 | 类型 | 说明 |
|---|---|---|
| warehouse | string | 仓库编码 |
| country | string | 国家 |
| distance | int | 距离(公里) |

### 样例数据

orders: (1001,SKU001,2,US), (1002,SKU002,1,UK), (1003,SKU003,3,FR)  
warehouse_stock: WH_US(SKU001=10,SKU002=0), WH_UK(SKU001=5,SKU002=8,SKU003=2), WH_FR(SKU003=10,SKU001=3)  
warehouse_distance: WH_US→US=200, WH_UK→US=5500, WH_US→UK=5800, WH_UK→UK=150, WH_FR→UK=400, WH_UK→FR=500, WH_FR→FR=100, WH_US→FR=6200

### 预期输出

| order_id | sku_id | country | best_warehouse | min_distance_km | estimated_delivery_hours |
|---|---|---|---|---|---|
| 1001 | SKU001 | US | WH_US | 200 | 301.0 |
| 1002 | SKU002 | UK | WH_UK | 150 | 226.0 |
| 1003 | SKU003 | FR | WH_FR | 100 | 151.0 |

### SQL

```sql
SELECT order_id, sku_id, country,
       warehouse AS best_warehouse,
       distance AS min_distance_km,
       ROUND(distance * 1.5 + 1, 1) AS estimated_delivery_hours
FROM (
    SELECT o.order_id, o.sku_id, o.country,
           ws.warehouse, wd.distance,
           ROW_NUMBER() OVER (PARTITION BY o.order_id ORDER BY wd.distance ASC) AS rn
    FROM orders o
    JOIN warehouse_stock ws 
        ON o.sku_id = ws.sku_id AND ws.stock >= o.qty
    JOIN warehouse_distance wd 
        ON ws.warehouse = wd.warehouse AND o.country = wd.country
) t
WHERE rn = 1;
```

**考点**：三表 JOIN + 库存过滤 (stock ≥ qty) + ROW_NUMBER 取最优 + 业务公式计算
