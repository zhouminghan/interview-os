# 一句话

写 SQL 要同时关注「结果正确」和「执行高效」：口径、NULL、去重、分区裁剪、join 策略、数据倾斜。

# 30 秒回答

注意分区裁剪、避免 select *、过滤前置、join 时小表广播或调序、注意 NULL 和类型一致、避免 count(distinct) 大开销、留意数据倾斜和单 key 长尾。

# 1 分钟回答

- 正确性：过滤条件位置、NULL 处理、去重、类型一致、口径一致
- 性能：分区裁剪、谓词下推、列裁剪、join 顺序、小表 broadcast、减少 shuffle
- 常见坑：count(distinct) 开销大、数据倾斜、笛卡尔积、大字段扫描
- 习惯：先看执行计划，再看耗时和 shuffle 量
