# 一句话

按月份分区、消费金额倒序取 `ROW_NUMBER()=1`，就是每月最大金额及其对应日期。

# 30 秒回答

`ROW_NUMBER() OVER (PARTITION BY DATE_FORMAT(consume_date,'yyyy-MM') ORDER BY consume_amount DESC)` 取 rn=1。

# 1 分钟回答

```sql
SELECT month_str, consume_date, consume_amount
FROM (
  SELECT consume_date, consume_amount,
         DATE_FORMAT(consume_date, 'yyyy-MM') AS month_str,
         ROW_NUMBER() OVER (
           PARTITION BY DATE_FORMAT(consume_date, 'yyyy-MM')
           ORDER BY consume_amount DESC
         ) AS rn
  FROM t_consumption
) t
WHERE rn = 1;
```

- 并列最大：要全返回用 `RANK()` 或 `DENSE_RANK()`，只要一条用 `ROW_NUMBER()`
- 优化：加日期分区裁剪、只在近 N 月时加 WHERE 减窗口计算量
- 高频查询可在 DWS 层预聚合「每月 Top1」小表
