**查询每个月购买订单 ≥ 3 笔 且 花费总金额 ≥ 200 的用户明细。按月份升序、购买金额降序。**
# 预期输出
| 月份 | 用户ID | 当月购买订单数 | 当月花费金额 |
|---|---|---|---|
| 2021-06 | S_001 | 3 | 256.7 |
| ... | ... | ... | ... |
# 参考解法
```sql
SELECT
  DATE_FORMAT(pay_dt, 'yyyy-MM') AS month,
  user_id,
  COUNT(DISTINCT order_id) AS order_cnt,
  SUM(cost_amt) AS total_amt
FROM dw_shein_pay_order_da
GROUP BY DATE_FORMAT(pay_dt, 'yyyy-MM'), user_id
HAVING COUNT(DISTINCT order_id) >= 3 AND SUM(cost_amt) >= 200
ORDER BY month ASC, total_amt DESC;
```
