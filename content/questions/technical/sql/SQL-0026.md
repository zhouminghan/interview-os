# 一句话

FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT。

# 30 秒回答

先 from 拿表做 join，where 过滤行，group by 分组，having 过滤分组，select 选列/算聚合，order by 排序，limit 截断。

# 1 分钟回答

- 顺序：FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT
- where 在分组前过滤行，having 在分组后过滤组
- select 别名在 order by 可用，where 不可用（执行顺序靠后）
