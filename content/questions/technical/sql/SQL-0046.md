**查询 2021 年 7 月每日新用户的 30 日复购情况。**
- **新用户**：首次购买的用户
- **复购**：首次购买后 1~30 天内再次购买（如 9/1 新用户 → 统计 9/2 ~ 10/1）
- **30 日复购率** = 30 日内复购用户数 / 新用户数
# 预期输出
| 日期 | 国家 | 新用户数 | 30日复购用户数 | 30日复购金额 | 30日复购率 |
|---|---|---|---|---|---|
| 2021-07-01 | US | 20000 | 5000 | 400000 | 0.25 |
| ... | ... | ... | ... | ... | ... |
# 参考解法
```sql
WITH first_pay AS (
  -- 每个用户首次购买日期
  SELECT user_id, MIN(pay_dt) AS first_dt
  FROM dw_shein_pay_order_da
  GROUP BY user_id
),
july_new AS (
  -- 7 月新用户（首次购买在 7 月）+ 首个购买日的国家
  SELECT f.user_id, f.first_dt, o.country
  FROM first_pay f
  JOIN (SELECT user_id, country, pay_dt FROM dw_shein_pay_order_da) o
    ON f.user_id = o.user_id AND f.first_dt = o.pay_dt
  WHERE f.first_dt BETWEEN '2021-07-01' AND '2021-07-31'
),
repurchase AS (
  -- 新用户首次购买后 1~30 天内的复购
  SELECT 
    j.first_dt,
    j.country,
    j.user_id,
    COUNT(DISTINCT o.order_id) AS repurchase_cnt,
    SUM(o.cost_amt) AS repurchase_amt
  FROM july_new j
  LEFT JOIN dw_shein_pay_order_da o
    ON j.user_id = o.user_id
    AND o.pay_dt BETWEEN DATE_ADD(j.first_dt, 1) AND DATE_ADD(j.first_dt, 30)
  GROUP BY j.first_dt, j.country, j.user_id
)
SELECT
  first_dt AS dt,
  country,
  COUNT(DISTINCT user_id) AS new_user_cnt,
  SUM(CASE WHEN repurchase_cnt > 0 THEN 1 ELSE 0 END) AS repurchase_user_cnt,
  SUM(COALESCE(repurchase_amt, 0)) AS repurchase_amt,
  ROUND(SUM(CASE WHEN repurchase_cnt > 0 THEN 1 ELSE 0 END) * 1.0 / COUNT(DISTINCT user_id), 4) AS repurchase_rate
FROM repurchase
GROUP BY first_dt, country
ORDER BY first_dt, country;
```
