# 一句话

用 `from_json` 把 JSON 字符串按 schema 转结构体，`explode` 展开数组，`transform` 处理数组内元素，单引号 JSON 先 replace 成双引号。

# 30 秒回答

字段里塞整个 JSON 时：先定义 schema，`from_json(col, schema)` 转 struct，再 `explode` 展开 array，最后 `select` 提取字段。Hive 不支持 from_json 的场景用 get_json_object + LATERAL VIEW explode；单引号 JSON 先 `regexp_replace` 成双引号。

# 1 分钟回答

```sql
SELECT id, name, type
FROM (
  SELECT explode(transform(
    from_json(v5, 'array<struct<id:bigint,name:string,type:array<string>>>'),
    x -> x
  )) AS e
) t;
```

- from_json：字符串按 schema 解析成 struct/array
- explode：把数组一行拆多行
- transform：数组内元素做变换
- 单引号 JSON：先 replace 成双引号再解析
- 平台不支持 from_json：用 get_json_object 逐字段取
