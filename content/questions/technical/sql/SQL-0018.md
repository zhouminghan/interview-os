# 一句话

逻辑上窗口函数在 WHERE 之后、ORDER BY 之前执行。

# 30 秒回答

执行顺序：FROM → WHERE → GROUP BY → HAVING → 窗口函数 → ORDER BY → LIMIT；所以窗口函数不能写在 WHERE 里，要过滤结果需外层子查询。

- 为什么窗口函数不能直接在 WHERE 用？
- 要对窗口结果过滤怎么写？
