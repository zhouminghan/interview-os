# 代码

```sql
SELECT modal, COUNT(*) AS cnt, AVG(quality_score) AS avg_score
FROM (
  SELECT id, modal, quality_score,
         PERCENT_RANK() OVER (PARTITION BY modal ORDER BY quality_score DESC) AS pct
  FROM sample
) t
WHERE pct <= 0.3
GROUP BY modal;
```

# 注意

- PERCENT_RANK 按质量分降序排，取前 30%
- 也可用 ROW_NUMBER 配合总数计算比例
