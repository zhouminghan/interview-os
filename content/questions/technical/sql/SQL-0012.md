# 1. 历史累计充值

```sql
SELECT user_id, SUM(pay_amount) AS total_amount
FROM pay
GROUP BY user_id;
```

# 2. 充值金额最高的日期及金额

```sql
SELECT user_id, pay_date, pay_amount
FROM (
  SELECT user_id, pay_date, pay_amount,
         ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY pay_amount DESC, pay_date DESC) AS rn
  FROM pay
) s
WHERE rn = 1;
```

# 3. 连续 7 天没有充值记录的用户

```sql
SELECT DISTINCT user_id
FROM pay p
WHERE NOT EXISTS (
  SELECT 1 FROM pay p2
  WHERE p2.user_id = p.user_id
    AND p2.pay_date >= DATE_SUB(CURRENT_DATE, INTERVAL 7 DAY)
);
```

# 注意

- 并列最高金额用 RANK/DENSE_RANK 按业务需要
- 「连续 7 天无充值」要先确认口径：是最近 7 天还是任意连续 7 天窗口
