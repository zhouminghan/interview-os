# 一句话

这是数据倾斜，核心是把集中的大 key 打散或提前聚合，让任务负载均衡。

# 30 秒回答

用两阶段聚合（加随机前缀再聚合）、过滤无效数据、开启倾斜优化参数（Hive skew join、Spark AQE skew join）、把大 key 拆分或单独处理、增加并行度。

# 1 分钟回答

- 两阶段聚合：group by 时给 key 加随机前缀先局部聚合，再按原 key 二次聚合
- 过滤：提前过滤无效或异常数据，降低单 key 量级
- join 倾斜：小表 broadcast、大表加盐、拆分热点 key 分别 join 再 union
- 参数：Hive `hive.optimize.skewjoin`、Spark `spark.sql.adaptive.skewJoin.enabled`
- 并行度：增加 reduce/task 数，避免单分区过载
