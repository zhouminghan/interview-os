# 思路

经典「日期减序号」法：连续日期减去连续序号得到相同值，按此值分组取 MIN/MAX 即为起止日期。

# 代码

```sql
WITH login_dedup AS (
    SELECT DISTINCT user_id, login_date FROM user_login
),
login_grp AS (
    SELECT user_id, login_date,
           DATE_SUB(login_date, ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY login_date)) AS grp
    FROM login_dedup
)
SELECT user_id,
       MIN(login_date) AS start_date,
       MAX(login_date) AS end_date,
       DATEDIFF(MAX(login_date), MIN(login_date)) + 1 AS consecutive_days
FROM login_grp
GROUP BY user_id, grp
ORDER BY user_id, start_date;
```

# 核心

连续日期 1/2/3 号，ROW_NUMBER 1/2/3，日期减序号得到同一个值，说明连续。
