# 思路

用 LEAD 取每个用户每次行为的「下一个行为」，筛出当前行为是登录的记录，统计下一行为频次取 TOP1。

# 代码

```sql
WITH action_with_next AS (
    SELECT user_id, action_type, action_time,
           LEAD(action_type) OVER (PARTITION BY user_id ORDER BY action_time) AS next_action
    FROM user_action
)
SELECT next_action, COUNT(*) AS cnt
FROM action_with_next
WHERE action_type = 'login' AND next_action IS NOT NULL
GROUP BY next_action
ORDER BY cnt DESC
LIMIT 1;
```

# 注意

- LEAD 按用户分区、按时间排序
- 过滤当前行为是登录，next_action 即登录后的下一个行为
