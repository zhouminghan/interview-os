# 一句话

常用窗口函数做排序、去重取最新、前后行、累计和滑动统计。

# 30 秒回答

row_number/rank/dense_rank 排序去重，lag/lead 取前后行，sum/count/avg over 做累计和滑动窗口，first_value/last_value 取首尾值。

# 1 分钟回答

- 排序：row_number/rank/dense_rank
- 前后行：lag/lead
- 聚合：sum/count/avg over（累计、移动平均）
- 首尾：first_value/last_value
- 场景：去重取最新、环比、累计、移动平均
