question: 求没挂过科的同学 / 至少挂过两科的同学
difficulty: 0

**表结构推测**：`student_scores(student_id, course_id, score)`，挂科 = score < 60

```sql
-- 没挂过科：所有课程 score >= 60
SELECT student_id
FROM student_scores
GROUP BY student_id
HAVING MIN(score) >= 60;

-- 至少挂过两科
SELECT student_id
FROM student_scores
WHERE score < 60
GROUP BY student_id
HAVING COUNT(*) >= 2;
```
