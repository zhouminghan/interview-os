# 一句话

复杂 SQL 优化先看执行计划定位慢点，再用「少读、少 shuffle、少重复」的思路改写。

# 30 秒回答

谓词下推、列裁剪、join 重排序、小表广播、CTE 拆分复杂嵌套、避免重复子查询、减少 count(distinct)、用窗口函数替代多次自连接、避免笛卡尔积。

# 1 分钟回答

- 定位：执行计划、慢 task、数据倾斜、重复扫描、多次 shuffle
- 优化：谓词下推、列裁剪、小表 broadcast、join 顺序
- 改写：复杂嵌套改 CTE 分步、union all 合并、条件聚合、窗口函数去重
- 去重：count(distinct) 改 group by 或两阶段去重
- 缓存：复用中间结果用临时表/物化
- 验证：执行计划、耗时、shuffle 量对比
