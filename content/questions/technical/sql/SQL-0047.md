**查询不同国家用户两次购买行为的平均时间间隔。**
- 只购买过一次的用户不参与计算
- 一天内同一用户多次下单只算一次（按天去重）
# 预期输出
| 国家 | 平均间隔天数 |
|---|---|
| US | 1.76 |
| UK | 3.82 |
| ... | ... |
# 参考解法
```sql
WITH daily_pay AS (
  -- 按用户 + 日期去重（一天多次下单算一次）
  SELECT DISTINCT user_id, pay_dt, country
  FROM dw_shein_pay_order_da
),
pay_with_lag AS (
  -- 每个用户每次购买的日期 + 下一次购买日期
  SELECT 
    country, user_id, pay_dt,
    LEAD(pay_dt) OVER (PARTITION BY user_id ORDER BY pay_dt) AS next_dt
  FROM daily_pay
),
intervals AS (
  -- 计算相邻两次购买间隔天数
  SELECT 
    country,
    user_id,
    DATEDIFF(next_dt, pay_dt) AS gap_days
  FROM pay_with_lag
  WHERE next_dt IS NOT NULL  -- 排除最后一次购买（没有下一次）
)
SELECT
  country,
  ROUND(AVG(gap_days), 2) AS avg_gap_days
FROM intervals
GROUP BY country
ORDER BY country;
```
