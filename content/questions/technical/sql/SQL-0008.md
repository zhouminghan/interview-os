# 思路

先按「用户 + 日期 + 网站」聚合访问次数，再用 ROW_NUMBER 在每个「用户 + 日期」内按次数排序，取前 10。

# 代码

```sql
SELECT user_id, dt, website, cnt
FROM (
  SELECT user_id, dt, website, cnt,
         ROW_NUMBER() OVER (PARTITION BY user_id, dt ORDER BY cnt DESC) AS rn
  FROM (
    SELECT user_id,
           to_date(visit_time) AS dt,
           website,
           COUNT(*) AS cnt
    FROM visit_log
    GROUP BY user_id, to_date(visit_time), website
  ) t
) s
WHERE rn <= 10;
```

# 注意

- 并列名次用 RANK/DENSE_RANK 按业务需要
- 日期要用日期粒度（to_date），不能用原始时间戳
- 大数据量可加分区裁剪和预聚合
