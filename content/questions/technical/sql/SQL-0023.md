# 一句话

留存率 = 某天新增用户在 N 天后仍活跃的人数 / 当天新增人数；用首登日期自关联，按 `datediff` 分组统计。

# 30 秒回答

先取每个用户首次登录日期，再 join 活跃日志，按「首登日期 + datediff(活跃日期, 首登日期)」分组 count distinct user_id，除以首登当天新增数即得次日/7 日留存。

# 1 分钟回答

```sql
WITH first_login AS (
  SELECT user_id, MIN(login_date) AS first_date
  FROM login GROUP BY user_id
)
SELECT fl.first_date,
       COUNT(DISTINCT CASE WHEN DATEDIFF(l.login_date, fl.first_date) = 1 THEN l.user_id END) / COUNT(DISTINCT fl.user_id) AS day1_retention
FROM first_login fl
LEFT JOIN login l ON l.user_id = fl.user_id
  AND DATEDIFF(l.login_date, fl.first_date) BETWEEN 1 AND 7
GROUP BY fl.first_date;
```

- 次日留存 = datediff 1，7 日留存 = 1~7 内还活跃
- 分母是首登当天的新增用户数
- 常按渠道/版本/地区分组对比
