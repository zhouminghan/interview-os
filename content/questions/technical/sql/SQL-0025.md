# 一句话

row_number 连续不重复；rank 有并列就跳号；dense_rank 有并列不跳号。

# 30 秒回答

分数 100/90/90/80：row_number 是 1/2/3/4；rank 是 1/2/2/4（并列后跳号）；dense_rank 是 1/2/2/3（并列不跳号）。取「前 N 条」用 row_number，取「前 N 名」用 dense_rank。

# 1 分钟回答

- row_number：每个分区分组内唯一连续编号，并列也随机给不同号
- rank：并列同名次，下一名跳号
- dense_rank：并列同名次，下一名连续不跳号
- 场景：取每组 TopN 条用 row_number；按名次取人用 dense_rank；排名展示用 rank
