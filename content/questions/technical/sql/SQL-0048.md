## 题目描述

计算每个月、每个品类、不同类型用户的用户数量。共 6 个指标：

| 指标 | 定义 |
|---|---|
| **品类新会员数** | 统计月当月首次购买该品类的用户数 |
| **品类老会员数** | 截止统计月之前购买过该品类，且统计月内再次购买该品类的用户数 |
| **品类老会员复购数** | 截止统计月之前购买过该品类，且在统计月内再次购买该品类的用户数（同一批老会员中有多少人复购） |
| **当期新会员转化数** | 当期新会员（首次消费在统计月内的用户）中，有多少人购买了该品类 |
| **品类历史新会员数** | 截止统计月之前有过购买行为、但从未买过该品类的用户数 |
| **品类历史新会员转化数** | 品类历史新会员中，统计月内首次购买了该品类的用户数 |

## 表结构

**`dw_order_detail_df`** — 全量销售明细表

| 字段 | 类型 | 说明 |
|---|---|---|
| pay_time | varchar | 付款时间 (yyyy-MM-dd HH:mm:ss)，同一秒最多一个订单 |
| sku | varchar | 商品名称 |
| user_id | varchar | 用户 ID |
| cate_nm | varchar | 品类名称 |

## 预期输出

以 2021-12 为例：

| 月份 | 品类 | 品类新会员数 | 品类老会员数 | 品类老会员复购数 | 当期新会员转化数 | 品类历史新会员数 | 品类历史新会员转化数 |
|---|---|---|---|---|---|---|---|
| 2021-12 | A | 100 | 1000 | 300 | 20 | 20000 | 80 |
| 2021-12 | B | 100 | 1000 | 300 | 20 | 20000 | 80 |
| 2021-12 | C | 100 | 1000 | 300 | 20 | 20000 | 80 |

## 解题思路

核心是算出三个中间结果：

1. **每个用户每个品类的首次购买月份**（`first_cate_month`）
2. **每个用户每个月的品类购买情况**（`user_month_cate_buy` — 是否购买）
3. **每个用户的首次购买月份**（`first_month`）

然后按月、按品类 JOIN 统计 6 个指标。

## 参考解法

```sql
WITH 
-- Step 1: 维度展开（月 + 品类 + 用户）
monthly_detail AS (
  SELECT 
    DATE_FORMAT(pay_time, 'yyyy-MM') AS stat_month,
    cate_nm,
    user_id
  FROM dw_order_detail_df
  GROUP BY DATE_FORMAT(pay_time, 'yyyy-MM'), cate_nm, user_id
),

-- Step 2: 每个用户每个品类的首次购买月份
first_cate AS (
  SELECT user_id, cate_nm, 
         MIN(stat_month) AS first_cate_month
  FROM monthly_detail
  GROUP BY user_id, cate_nm
),

-- Step 3: 每个用户首次购买的月份（全局）
first_user AS (
  SELECT user_id, MIN(stat_month) AS first_month
  FROM monthly_detail
  GROUP BY user_id
),

-- Step 4: 按月+品类展开所有组合
all_combos AS (
  SELECT DISTINCT stat_month, cate_nm FROM monthly_detail
),

-- Step 5: 主统计
detail AS (
  SELECT 
    m.stat_month,
    m.cate_nm,
    m.user_id,

    -- 是否当月首次购买该品类
    CASE WHEN fc.first_cate_month = m.stat_month THEN 1 ELSE 0 END AS is_new_cate,

    -- 是否当月之前买过该品类
    CASE WHEN fc.first_cate_month < m.stat_month THEN 1 ELSE 0 END AS is_old_cate,

    -- 是否老会员且当月复购
    CASE WHEN fc.first_cate_month < m.stat_month THEN 1 ELSE 0 END AS is_old_cate_repurchase,

    -- 是否当期新会员（首次消费在当月）
    CASE WHEN fu.first_month = m.stat_month THEN 1 ELSE 0 END AS is_new_user,

    -- 是否历史会员但没买过该品类
    CASE WHEN fu.first_month < m.stat_month AND fc.first_cate_month IS NULL THEN 1 ELSE 0 END AS is_hist_no_cate,

    -- 历史没买过 + 当月首次买
    CASE WHEN fu.first_month < m.stat_month AND fc.first_cate_month = m.stat_month THEN 1 ELSE 0 END AS is_hist_convert

  FROM monthly_detail m
  LEFT JOIN first_cate fc ON m.user_id = fc.user_id AND m.cate_nm = fc.cate_nm
  LEFT JOIN first_user fu ON m.user_id = fu.user_id
)

SELECT 
  stat_month AS month,
  cate_nm AS category,

  -- 品类新会员数
  SUM(is_new_cate) AS new_cate_users,

  -- 品类老会员数（之前买过 + 当月再次购买）
  SUM(is_old_cate) AS old_cate_users,

  -- 品类老会员复购数（和老会员数口径相同：之前买过且当月买了）
  SUM(is_old_cate_repurchase) AS old_cate_repurchase,

  -- 当期新会员转化数
  SUM(CASE WHEN is_new_user = 1 AND is_new_cate = 1 THEN 1 ELSE 0 END) AS new_user_convert,

  -- 品类历史新会员数
  SUM(is_hist_no_cate) AS hist_no_cate_users,

  -- 品类历史新会员转化数
  SUM(is_hist_convert) AS hist_convert_users

FROM detail
GROUP BY stat_month, cate_nm
ORDER BY stat_month, cate_nm;
```

### 关键点

- `first_cate_month` vs `first_month`：品类首次 vs 全局首次。前者用于判断「品类新/老」，后者用于判断「当期新会员」
- `first_cate_month IS NULL`：该用户从未买过该品类 → 历史新会员的候选
- 老会员数和老会员复购数在当前逻辑下结果相同（都是「之前买过且当月买了」），如有额外过滤条件可分开
