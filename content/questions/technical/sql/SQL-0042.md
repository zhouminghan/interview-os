**难度**：⭐⭐⭐

**业务场景**：SHEIN 每天大量新品上架，需评估首周市场表现。

**题目**：统计每个上新商品在上架后 **7 天内**的累计销量。无销量的也要显示。

### 表结构

**`product_launch`** — 商品上架时间

| 字段 | 类型 | 说明 |
|---|---|---|
| sku_id | string | SKU |
| launch_time | string | 上架时间 |

**`order_detail`** — 订单明细

| 字段 | 类型 | 说明 |
|---|---|---|
| order_id | bigint | 订单 ID |
| sku_id | string | SKU |
| qty | int | 购买数量 |
| order_time | string | 下单时间 |

### 样例数据

SKU001 (6/1 上架)：3 单 (6/2, 6/5, 6/9)  
SKU002 (6/3 上架)：3 单 (6/4, 6/8, 6/12) → 6/12 超过 7 天不计  
SKU003 (6/5 上架)：2 单 (6/6, 6/14) → 6/14 超过 7 天不计

### 预期输出

| sku_id | launch_time | first_week_sales |
|---|---|---|
| SKU001 | 2025-06-01 08:00 | 3 |
| SKU002 | 2025-06-03 10:00 | 3 |
| SKU003 | 2025-06-05 09:00 | 1 |

### SQL

```sql
SELECT l.sku_id, l.launch_time,
       COALESCE(SUM(o.qty), 0) AS first_week_sales
FROM product_launch l
LEFT JOIN order_detail o 
    ON l.sku_id = o.sku_id
    AND DATEDIFF(o.order_time, l.launch_time) BETWEEN 0 AND 6
GROUP BY l.sku_id, l.launch_time;
```

**考点**：LEFT JOIN + DATEDIFF 时间窗口 + COALESCE 空值处理
