**查询每个月、不同收货国家、购买金额排名前 300 名的新用户信息。**
- **新用户**：首次购买的用户
- **新用户订单**：首次购买当天所有订单都算
- **排名**：金额相同则并列，不连续（RANK）
# 预期输出
| 月份 | 国家 | 用户类型 | 用户ID | 新用户订单数 | 新用户购买金额 | 排名 |
|---|---|---|---|---|---|---|
| 2021-06 | US | 新用户 | S_002 | 5 | 800 | 1 |
| ... | ... | ... | ... | ... | ... | ... |
# 参考解法
```sql
WITH first_pay AS (
  -- 每个用户首次购买日期
  SELECT user_id, MIN(pay_dt) AS first_dt
  FROM dw_shein_pay_order_da
  GROUP BY user_id
),
new_user_orders AS (
  -- 新用户首次购买当天所有订单
  SELECT 
    DATE_FORMAT(o.pay_dt, 'yyyy-MM') AS month,
    o.country,
    o.user_id,
    COUNT(DISTINCT o.order_id) AS order_cnt,
    SUM(o.cost_amt) AS total_amt
  FROM dw_shein_pay_order_da o
  INNER JOIN first_pay f 
    ON o.user_id = f.user_id AND o.pay_dt = f.first_dt
  GROUP BY DATE_FORMAT(o.pay_dt, 'yyyy-MM'), o.country, o.user_id
)
SELECT
  month, country,
  '新用户' AS user_type,
  user_id, order_cnt, total_amt,
  RANK() OVER (PARTITION BY month, country ORDER BY total_amt DESC) AS rank
FROM new_user_orders
QUALIFY RANK() OVER (PARTITION BY month, country ORDER BY total_amt DESC) <= 300;
```
