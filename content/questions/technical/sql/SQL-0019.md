# 一句话

把 login 当 +1、logout 当 -1，按时间排序后累加，累加值的最大值就是峰值在线人数。

# 30 秒回答

UNION ALL 把登录/登出合并成事件流，登录 +1、登出 -1，窗口函数 `SUM(delta) OVER (ORDER BY event_time, delta DESC)` 求累加，外层 `MAX` 取峰值。

# 1 分钟回答

```sql
SELECT MAX(online_cnt)
FROM (
  SELECT event_time,
         SUM(delta) OVER (ORDER BY event_time, delta DESC) AS online_cnt
  FROM (
    SELECT login_time AS event_time, 1 AS delta FROM user_session
    UNION ALL
    SELECT logout_time AS event_time, -1 AS delta FROM user_session
  ) e
) t;
```

- 关键点：同刻有登录又有登出时，`delta DESC` 让 +1 先算，避免「刚走又来」被判成 0
- 变式「求最大在线人数对应的时刻」：累加值第一次达到峰值的时间点
- 进阶「每天峰值」：加 `PARTITION BY DATE(event_time)`
