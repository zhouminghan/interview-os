# 一句话

inner 取交集，left/right 保留一侧全量，full 两侧都保留，semi 只返回左表存在匹配的行，anti 返回左表不匹配的行。

# 30 秒回答

inner join 两边都匹配才返回；left join 保留左表全量、右表匹配不上的填 null；full join 两边都保留；left semi join 只返回左表在右表有匹配的行且不返回右表列；left anti join 返回左表在右表不存在的行。

# 1 分钟回答

- inner：交集
- left/right：保留驱动侧全量
- full：全外连接，两侧都保留
- left semi：等价 `WHERE EXISTS`，只出左表列，去重语义
- left anti：等价 `WHERE NOT EXISTS`，找「没有」的记录
- 用途：semi 做过滤去重，anti 做差集/漏斗
