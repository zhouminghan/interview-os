# 一句话

UDF 一行进一行出，UDAF 多行进一行出（聚合），UDTF 一行进多行出（炸裂）。

# 30 秒回答

reduce 个数由分区数/并行度决定（Spark SQL 默认 200），与 group by key 数和数据量相关。
