# 一句话

行转列用 `CASE WHEN + MAX` 或 MAP 聚合，列转行用 `LATERAL VIEW EXPLODE`，TopN 用 `ROW_NUMBER`，连续行为用「日期减 ROW_NUMBER」分组。

# 30 秒回答

四个高频场景：行转列 `CASE WHEN` 展开再聚合；列转行 `EXPLODE`；分组 TopN `ROW_NUMBER OVER PARTITION BY ... ORDER BY ...` 取 rn<=N；连续行为用「排序号减连续号」得差值，差值相同即连续段。

# 1 分钟回答

- 行转列：`CASE WHEN cond THEN val END` + `MAX/GROUP BY`
- 列转行：`LATERAL VIEW EXPLODE(array)`
- TopN：`ROW_NUMBER() OVER (PARTITION BY key ORDER BY score DESC)` 取 rn<=N
- 连续行为：按用户分组按天排序得 `rn`，用 `date_sub(date, rn)` 做差值，相同差值聚成一段
- 数据量大的场景：先过滤再 explode，避免爆炸；TopN 注意热点 key 倾斜
