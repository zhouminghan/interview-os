# 一句话

按「严格大于 min 且严格小于 max」过滤，就能把并列的最高分、最低分全部去掉，再求平均。

# 30 秒回答

用 `JOIN (SELECT course_id, MIN(score), MAX(score) GROUP BY course_id)` 拿到每门课上下界，主表 `WHERE score > min AND score < max` 再 `AVG`。严格不等号天然排除所有并列最值。

# 1 分钟回答

```sql
SELECT s.course_id, AVG(s.score) AS avg_score
FROM score s
JOIN (
  SELECT course_id, MIN(score) AS min_s, MAX(score) AS max_s
  FROM score GROUP BY course_id
) t ON s.course_id = t.course_id
WHERE s.score > t.min_s AND s.score < t.max_s
GROUP BY s.course_id;
```

- 陷阱：不能只删一条，题目要求并列的最高/最低都去掉
- 边界：某课所有人同分（min=max）会全过滤成 NULL，按业务看是否要返回原平均分
- 边界：某课只有 1~2 人时去掉后无数据，也属合理
