# 方法一：窗口函数

```sql
SELECT user_id, order_id, amount
FROM (
  SELECT user_id, order_id, amount,
         ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY amount DESC) AS rn
  FROM orders
) t
WHERE rn = 1;
```

# 方法二：子查询 + JOIN

```sql
SELECT o.user_id, o.order_id, o.amount
FROM orders o
JOIN (
  SELECT user_id, MAX(amount) AS max_amount
  FROM orders
  GROUP BY user_id
) t
ON o.user_id = t.user_id AND o.amount = t.max_amount;
```

# 注意

- 并列最大值：`ROW_NUMBER` 只留一条，`RANK`/`DENSE_RANK` 会保留并列，按业务需要选择
- 方法二在存在并列最大值时可能返回多条
- 单用户订单量巨大时要注意数据倾斜
