# 思路

按「品类 + 视频」聚合举报数，再用 ROW_NUMBER 在每个品类内按举报数排序取前 5。

# 代码

```sql
SELECT category_id, video_id, report_cnt
FROM (
  SELECT category_id, video_id, report_cnt,
         ROW_NUMBER() OVER (PARTITION BY category_id ORDER BY report_cnt DESC) AS rn
  FROM (
    SELECT category_id, video_id, COUNT(*) AS report_cnt
    FROM report_log
    GROUP BY category_id, video_id
  ) t
) s
WHERE rn <= 5;
```

# 百亿级数据量的问题

- group by 的 key 分布不均，热点品类/视频会数据倾斜
- count + 窗口排序都涉及 shuffle，数据量大时长尾
- 优化：热点 key 加盐两阶段聚合、分区裁剪、预聚合、必要时拆热点单独处理
