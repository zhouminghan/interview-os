# 一句话

查询优化分建模、SQL、执行三层：建表优化 + 语句改写 + 执行定位。

# 30 秒回答

建模层用分区/分桶/排序键/物化视图/索引；SQL 层做谓词下推、列裁剪、join 优化、避免 select *；执行层用 Profile/执行计划定位慢算子，调并行度和资源。

# 1 分钟回答

- 建模：分区裁剪、分桶均匀、排序键、物化视图、Bitmap/Bloom Filter
- SQL：谓词下推、列裁剪、join 重排序、减少 count(distinct)
- 执行：Profile 找慢算子、并行度、缓存
- 验证：耗时、扫描行数、shuffle 对比
