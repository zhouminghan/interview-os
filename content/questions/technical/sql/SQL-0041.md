**难度**：⭐⭐⭐

**业务场景**：SHEIN 需要监控每个 SKU 的库存周转效率。

**题目**：计算 **2025 年 6 月**每个 SKU 的库存周转天数 = 期间内平均库存量 / 期间内日均销量。

### 表结构

**`inventory_snapshot`** — 每日库存快照

| 字段 | 类型 | 说明 |
|---|---|---|
| snap_date | string | 日期 |
| sku_id | string | SKU |
| stock | int | 当日库存 |

**`daily_sales`** — 每日销量

| 字段 | 类型 | 说明 |
|---|---|---|
| sale_date | string | 日期 |
| sku_id | string | SKU |
| qty | int | 当日销量 |

### 样例数据

**inventory_snapshot**：SKU001 库存 500→480→460，SKU002 库存 300→280→250

**daily_sales**：SKU001 每天 20 件，SKU002 每天 20/30/25 件

### 预期输出

| sku_id | avg_stock | avg_daily_sales | turnover_days |
|---|---|---|---|
| SKU001 | 480.00 | 20.00 | 24.0 |
| SKU002 | 276.67 | 25.00 | 11.1 |

### SQL

```sql
SELECT sku_id, avg_stock, avg_daily_sales,
       ROUND(avg_stock / avg_daily_sales, 1) AS turnover_days
FROM (
    SELECT sku_id,
           ROUND(AVG(stock), 2) AS avg_stock,
           ROUND(SUM(qty) / COUNT(DISTINCT sale_date), 2) AS avg_daily_sales
    FROM (
        SELECT i.sku_id, i.stock,
               COALESCE(s.qty, 0) AS qty, s.sale_date
        FROM inventory_snapshot i
        LEFT JOIN daily_sales s 
            ON i.sku_id = s.sku_id AND i.snap_date = s.sale_date
        WHERE i.snap_date BETWEEN '2025-06-01' AND '2025-06-30'
    ) t
    GROUP BY sku_id
) tt;
```

**考点**：LEFT JOIN 保全集 + COALESCE 处理 NULL + 日均分母用 COUNT(DISTINCT)
