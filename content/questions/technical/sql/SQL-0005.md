# 题目理解

长表（多行序列）中把「当前行」与「下一行」的数值相加，可用窗口函数 LEAD 取下一行；变式是给两数加不同权重后再相加。

# 基础写法

```sql
SELECT id, val,
       val + LEAD(val) OVER (ORDER BY seq) AS pair_sum
FROM t;
```

# 权重变式

```sql
SELECT id, val,
       val * w1 + LEAD(val) OVER (ORDER BY seq) * w2 AS weighted_sum
FROM t;
```

# 注意

- LEAD 取下一行，LAG 取上一行，末行没有下一行时 LEAD 为 NULL，需要 NVL/COALESCE 处理
- 权重为常数时直接乘；若每行权重不同，需要先关联或再套一层窗口
- 若「下一列」指宽表相邻两列，则直接 col1 + col2 即可，先确认表结构
