# 一句话

ROWS 按「物理行数」界定帧（前后 N 行），RANGE 按「排序键的值范围」界定帧（值差在 N 内）；ORDER BY 有重复值时两者结果会不同。

# 30 秒回答

`ROWS BETWEEN 1 PRECEDING AND CURRENT ROW` 取「上一行 + 当前行」；`RANGE BETWEEN 1 PRECEDING AND CURRENT ROW` 取「值 - 1 到当前值」的所有行。排序键有并列时，RANGE 会把同值行都纳入，ROWS 只按行位置。

# 1 分钟回答

- ROWS：按行偏移，物理概念，`ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`
- RANGE：按值偏移，逻辑概念，`RANGE BETWEEN 100 PRECEDING AND CURRENT ROW`（数值型排序键）
- 差异点：ORDER BY 列有重复值时，RANGE 会把同值的一批行视为一个「peer group」
- 默认帧：有 ORDER BY 无 frame 时，默认 `RANGE UNBOUNDED PRECEDING AND CURRENT ROW`
- 注意：RANGE 需要排序键可比较，字符串/非数值排序键行为受限
