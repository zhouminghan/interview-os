difficulty: 0
topic: [SHEIN]
source_type: knowledge
---

| 指标 | 说明 |
|------|------|
| 日活(DAU) | `COUNT(DISTINCT user_id)` 按天 |
| 周活(WAU) | 近7天去重用户数 |
| 月活(MAU) | 近30天去重用户数 |
| 次日留存 | 当日新增中第二天还活跃的比例 |
| 三日/七日留存 | 同理，`MIN(login_date)` 取新增日 + JOIN 原表 |
