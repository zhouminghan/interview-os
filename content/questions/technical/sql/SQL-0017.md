# 一句话

CTE 是临时命名结果集，引擎可能内联展开（多次引用算多次）或物化（只算一次）。

# 30 秒回答

Spark SQL 默认内联展开 CTE，多次引用会重复计算；逻辑重且被多次引用的 CTE 可改用临时表物化，避免重复计算。
