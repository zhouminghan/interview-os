# 一句话

count(distinct) 单字段去重只能落到一个 reduce，易倾斜；换 group by 可两阶段并行去重。多个 count(distinct) 会各自独立去重，内存和耗时成倍涨。

# 30 秒回答

count(distinct) 用一个 reduce 做全量去重，数据量大时倾斜。换 `SELECT COUNT(*) FROM (SELECT ... GROUP BY key)` 让去重在分组阶段并行。多个 count(distinct) 会各自起一个去重结构，内存翻倍、性能差。

# 1 分钟回答

```sql
-- 原写法
SELECT COUNT(DISTINCT user_id) FROM t;
-- 优化写法
SELECT COUNT(*) FROM (SELECT user_id FROM t GROUP BY user_id) x;
```

- 多个 count(distinct)：`count(distinct a), count(distinct b)` 会维护多个去重集合，内存压力大
- 优化：拆成多个 group by 子查询再 join，或用 bitmap/去重表
