# 一句话

用执行计划/Profile 看耗时、扫描行数、shuffle 和慢算子，定位瓶颈再优化。

# 30 秒回答

看执行计划（EXPLAIN）和 Profile，找耗时、扫描数据量大的算子，判断是全表扫描、shuffle、join 还是倾斜，再针对性优化。

# 1 分钟回答

- 执行计划：看是否走索引/分区裁剪、join 策略
- Profile：看每个算子耗时、扫描行数、shuffle 量
- 定位：全表扫描、慢 join、数据倾斜、低效子查询
- 优化：加索引/物化视图、改写、调参
