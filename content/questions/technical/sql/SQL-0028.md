# 一句话

数据量极大且可接受少量误差时，用 `approx_count_distinct`（基于 HyperLogLog）做近似去重，内存和时间远低于精确 count(distinct)。

# 30 秒回答

精确 count(distinct) 要维护完整去重集合，大基数时内存大、单 reduce 慢；`approx_count_distinct(col, rsd)` 用 HyperLogLog 以 O(1) 近似空间估基数，误差可控（如 rsd=0.01 约 1% 误差）。

# 1 分钟回答

- 精确：维护集合，内存随基数线性增长，易倾斜
- 近似：HyperLogLog 概率结构，空间小、可并行
- 参数 rsd：控制相对标准差，越小越准但越慢
- 适用：UV 大盘、基数估算等可容忍误差的场景
- 不适用：对账、金融等要求精确的场景
