difficulty: 0

| 优势 | 说明 |
|------|------|
| **可扩展性** | 水平扩展，添加 broker 处理更多分区，无缝处理 PB 级数据 |
| **高性能** | 高吞吐量，批量写入和读取优化，远超传统数据库 |
| **持久性与可靠性** | 多节点复制数据，可配置冗余级别 |
| **容错性** | 个别组件故障时系统继续运行 |
| **实时处理** | 生产者写入 → 消费者以最小延迟读取 |
| **解耦** | 生产者和消费者独立运行，互不关心 |
| **可重放性** | 数据存储一段时间，新应用可重放历史数据 |
| **高可用性** | 分布式 + 复制模型，部分 broker/分区不可用时仍运行 |
