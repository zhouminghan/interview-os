# 一句话

Hive 提供数仓的存储、元数据和 SQL 查询能力。

# 参考回答

Hive 建在 HDFS 上，把文件映射成表，提供元数据管理和 SQL 查询，天然就是数仓的存储和计算层。特点是能用 SQL、能管海量数据、和 Hadoop 生态集成好。
