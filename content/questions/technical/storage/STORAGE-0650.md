question: HBase 和 Hive 的区别？
difficulty: 0
topic: []
source_type: knowledge
---

HBase 是一个 NoSQL 数据库。它支持记录级别的 update、insert 和 delete 语句。HBase 不支持类似 SQL 的查询语言。但可以将 Hive 与 HBase 一起用于查询目的。Hive 运行在 MapReduce 上，HBase 运行在 HDFS 上。Apache Hive 是一个用于数据仓库和数据分析的框架，用于数据仓库应用。HBase 是 HDFS 之上的 NoSQL 数据库。
