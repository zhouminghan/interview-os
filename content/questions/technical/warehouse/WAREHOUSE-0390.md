# 一句话

①是标准 7 日留存，②是 7 日回访不是留存，面试一定要先区分口径再谈建模。

# 30 秒回答

这题的陷阱就在两种口径混为一谈。互联网通用的 7 日留存是：T 日注册新增用户，在 T+7 日当天有活跃行为；第二种叫 7 日回访（7 日内任意一天回来过），数值会明显高于留存。建模上用 DWD 用户注册表 + DWD 用户活跃表，DWS 层做新增用户宽表标记注册日期，再关联后续活跃记录。

# 1 分钟回答

- 口径区分：7 日留存（T+7 当天活跃）vs 7 日回访（T+1~T+7 任意一天活跃），后者不是留存
- 建模：DWD 用户注册表、DWD 用户活跃表，DWS 新增用户宽表标记注册日期，关联后续活跃记录
- 坑一：跨自然日时区问题，统一用业务时区而不是服务器时区
- 坑二：用户多设备登录，统一用账号 ID 而不是设备 ID
- 坑三：注册时间和活跃时间跨月，分区关联要注意别漏分区
- 坑四：新增用户要剔除测试账号和内部账号
- 坑五：留存口径容易混淆，必须用指标字典固化
