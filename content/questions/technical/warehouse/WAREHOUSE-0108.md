# 一句话

四步搭建：选 OMTM 关键指标 → AARRR 模型拆解 → 业务流方法拆维度 → 功能模块监控体系。

# 30 秒回答

第一步 OMTM（One Metric That Matters）：社交看 DAU、电商看 GMV、视频看时长；第二步 AARRR（获取/活跃/留存/营收/自传播）拉指标树；第三步按维度（时间/人口/产品）+ 指标（新增/活跃/留存）拆解；第四步建功能矩阵 + 使用路径 + 分功能指标体系。

# 1 分钟回答

- OMTM：每个业务只选一个最重要的北极星指标
- AARRR：获取→活跃→留存→营收→自传播，逐层拆指标
- 业务流：整体/内容/渠道/产品多维拆解
- 功能模块监控：大众/核心/小众功能矩阵 + 使用路径 + 分功能指标
- 举例：抖音关键指标 = 新增/DAU/日均时长/留存/收入
