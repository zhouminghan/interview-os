# 一句话

需求评审 -> 口径定义 -> 设计 -> 开发 -> 对账 -> 评审 -> 上线 -> 监控。

# 30 秒回答

先做需求评审和口径澄清，再定指标、粒度、分层和建模方案，开发后自测/对账，评审通过后上线并监控。

# 1 分钟回答

1. 需求评审：口径、维度、粒度、周期
2. 设计：分层、建模、复用评估
3. 开发：SQL/ETL、调度
4. 对账：新旧口径、跨层校验
5. 评审 + 上线 + 监控
