# 一句话

指标体系 = 指标字典 + 分层指标（原子/派生/复合），统一口径和维度。

# 30 秒回答

原子指标是最小不可拆度量（如支付金额）；派生指标 = 原子指标 + 修饰词/维度（如近 7 日某品类支付金额）；复合指标由多个指标运算得到（如客单价 = 金额/单量）。

# 1 分钟回答

- 原子指标：最小粒度、不可拆
- 派生指标：原子 + 维度 + 统计周期
- 复合指标：多指标运算
- 指标字典：名称、口径、维度、粒度、公式、负责人
- 目的：统一口径、避免重复、可复用
