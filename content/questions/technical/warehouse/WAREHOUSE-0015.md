# 一句话

退款会影响交易类指标的口径，核心是定义清楚「退款按申请时间还是完成时间」、以及订单与退款如何关联。

# 30 秒回答

影响的指标：下单量、支付金额、净交易额、退款金额、退款率、订单状态、优惠/佣金。退款处理要把退款事实与订单正确关联，按统一口径做净额计算，避免重复扣减。

# 1 分钟回答

- 订单状态机：已下单 -> 已支付 -> 部分/全额退款 -> 已关闭
- 退款相关指标：退款单量、退款金额、退款率、退款时长
- 口径要定：按申请时间还是完成时间；是否扣减优惠；部分退款怎么算
- 建模：退款事实表与订单事实表分开，或订单表加退款标记
- 净额：实付 - 退款，按订单号对账、流水幂等去重
