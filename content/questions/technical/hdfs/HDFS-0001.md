# 一句话

NameNode 管元数据和文件到 block 的映射，DataNode 存实际数据；客户端读写都先问 NameNode 要 DataNode 位置，再和 DataNode 传数据。

# 30 秒回答

写：请求 NameNode 创建文件 -> 返回 DataNode 列表 -> 按 block 写入第一个 DataNode -> 管道式复制到副本 -> 完成确认，NameNode 更新元数据。
读：请求 NameNode 拿 block 位置 -> 返回就近排序的 DataNode -> 逐个 block 读取。

# 1 分钟回答

写流程：
1. client 向 NameNode 发创建请求，检查权限/配额
2. NameNode 返回 DataNode 列表（按副本策略）
3. client 写第一个 DataNode，DataNode 间 pipeline 复制到其余副本
4. 每个 block 写完发确认，最后一个 block 写完关文件，NameNode 更新元数据

读流程：
1. client 向 NameNode 请求文件元数据
2. NameNode 返回 block 位置，按网络距离排序
3. client 就近从 DataNode 读每个 block
4. 读完所有 block 返回
