# 一句话

HDFS 是 Master-Slave 分布式文件系统：NameNode 管元数据、DataNode 存数据块，默认 3 副本容错。

# 30 秒回答

NameNode 管元数据（文件分几个 block、每个 block 在哪几个 DataNode），DataNode 存实际数据（默认 3 副本），SecondaryNameNode 帮 NameNode 合并 fsimage 和 editlog。Hive 表底层就存在 HDFS 上。

# 1 分钟回答

- NameNode：元数据节点，维护目录树和 block 到 DataNode 的映射，是单点
- DataNode：数据节点，存 block 数据，定时向 NameNode 心跳 + 上报块信息
- SecondaryNameNode：定期合并 fsimage 和 editlog，不是热备
- 副本：默认 3 副本，一个 rack 内一个 + 跨 rack 一个，保证容错
- 读写：大文件顺序读写，不适合小文件（元数据压力大）
