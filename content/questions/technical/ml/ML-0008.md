# 一句话

重复样本让模型把同一个例子记得更重，评估被高估，还会拖慢训练、放大偏差。

# 30 秒回答

影响：模型对重复样本过拟合，评估集和训练集泄漏时分数虚高，训练变慢，少数高频样本主导梯度。检测：文本用 MinHash/SimHash 找近重复，再上精确 hash 或语义相似度确认；有唯一 ID 的直接按 ID 去重。

# 1 分钟回答

- 影响：过拟合高频样本、评估虚高（泄漏）、训练慢、类别失衡
- 检测：精确 hash 去重 + MinHash/SimHash 近重复 + 语义去重
- 处理：去重、按来源限采样、给重复样本降权
- 注意：先查训练/验证/测试有没有跨集泄漏，再决定删哪些
- 指标：去重后监控样本量和分布变化，别把稀有类也删掉
