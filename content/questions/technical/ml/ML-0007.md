# 一句话

采样偏差是训练样本的选取方式和真实总体不一致，导致学到的规律偏向某个子群体。

# 30 秒回答

比如只拿活跃用户做训练，模型对沉默用户就没代表性。修复：先明确总体定义，用分层/配额采样保证各群体比例对齐，再给被低估的群体加权补偿，最后持续监控线上线下的分布差。

# 1 分钟回答

- 定义：样本不是从目标总体随机抽出来的，存在系统性偏斜
- 例子：只采样付费用户、只在白天采样、只拿能回填标签的样本
- 修复：定义总体 → 分层/配额采样 → 样本加权 → 采样偏差监控
- 影响：训练集有偏，线上泛化差，评估指标虚高
- 检测：对比训练集和真实总体的关键维度分布
