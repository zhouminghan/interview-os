# 一句话

Data Drift 是输入特征分布变了，Concept Drift 是「同样的输入，正确答案的含义变了」。

# 30 秒回答

Data Drift：模型看到的 X 分布和训练时不一样，比如用户年龄结构变了。Concept Drift：X 到 y 的映射关系变了，比如同样的浏览行为，过去算高意向，用户习惯变了之后不再代表高意向。监控上，Data Drift 用 PSI/KS 对比特征分布，Concept Drift 看模型效果和标签反馈的持续下滑。

# 1 分钟回答

- Data Drift：P(X) 变化，用 PSI/KS 逐特征监控
- Concept Drift：P(y|X) 变化，看线上效果、人工标注反馈
- 监控：特征分布 PSI 告警 + 模型指标趋势 + 定期重标注
- 处理：特征漂移做重采样/特征对齐；概念漂移做重训练/更新标签逻辑
- 定位：先分清是 Data Drift 还是 Concept Drift，再决定重训练还是修特征
