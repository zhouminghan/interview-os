# 一句话

skills 是给 Agent 的可复用指令包，把领域知识、工作流和资产封装起来，让 Agent 按规范执行。

# 30 秒回答

一个 skill 通常有 SKILL.md（name/description 触发路由 + 指令），可选 scripts、assets、references。作用是封装领域知识、规范流程、复用资产、按需触发。

# 1 分钟回答

- 结构：SKILL.md 的 frontmatter 写 name/description，正文写步骤、约束、验收
- scripts：可执行脚本，避免 Agent 重写大段代码
- assets/references：模板、参考资料
- 作用：按需触发、稳定输出、知识沉淀、复用
