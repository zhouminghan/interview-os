# 一句话

用「基线 RAG vs GraphRAG」做对照，指标看端到端准确率、召回率、答案忠实度（幻觉率）、延迟和成本，GraphRAG 在多跳/跨文档问题上收益最明显。

# 30 秒回答

构建前后对比：先跑一个普通向量 RAG 当基线，再上 GraphRAG（实体/关系抽取 + 图检索），同一批测试集打分。评测分两层：检索层看召回率/命中率，生成层看答案准确率、忠实度（有没有幻觉）、引用是否到位。结果通常是多跳推理类问题提升明显，单跳简单问题提升不大，还要权衡构建成本与查询延迟。

# 1 分钟回答

- 基线对照：Naive RAG（纯向量）vs GraphRAG（实体图谱 + 社区摘要）
- 检索指标：Recall@K、命中率、是否召回关键实体/关系
- 生成指标：答案准确率、忠实度/幻觉率、引用覆盖
- 成本指标：建图耗时、查询延迟、Token 消耗
- 典型结论：跨文档/多跳问题提升 10-20%，简单事实问答持平或略降
