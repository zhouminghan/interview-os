# 一句话

RAG 检索外部知识注入大模型再生成，传统搜索只返回文档列表。

# 30 秒回答

RAG：文档切块 → Embedding → 向量库 → 检索 top-k → 拼进 prompt → 模型生成答案；传统搜索只做召回排序，不生成答案。

```diagram
type: flow
title: RAG 链路
direction: LR
nodes:
  - id: chunk
    label: 文档切块
    color: blue
  - id: emb
    label: Embedding 向量化
  - id: vec
    label: 向量库存储
  - id: ret
    label: 检索 top-k
  - id: prompt
    label: 拼入 Prompt
  - id: gen
    label: LLM 生成答案
    color: green
edges:
  - from: chunk
    to: emb
  - from: emb
    to: vec
  - from: vec
    to: ret
    label: 用户问题
  - from: ret
    to: prompt
  - from: prompt
    to: gen
```
