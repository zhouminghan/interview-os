# 一句话

知识库维护：表/指标元数据、业务口径、血缘关系、FAQ 与示例、以及更新版本，保证 Agent 能拿到准确上下文。

# 30 秒回答

核心四类：表元数据（字段含义/类型/枚举值）、指标口径（定义/计算逻辑/负责人）、业务知识（术语/规则/常见问题）、示例（优质 SQL/问答对）。配版本管理和更新机制，过期内容要及时刷新。

# 1 分钟回答

- 表元数据：字段、类型、枚举、上下游关系
- 指标口径：定义、计算逻辑、负责人、使用场景
- 业务知识：术语、规则、FAQ
- 示例：优质 SQL、问答对、标注样例
- 配套：版本管理、更新流程、权限、质量校验
