# 一句话

Agent Skill 题通常考「给一个场景，设计一个可复用 skill 的结构、触发和验收」。

# 30 秒回答

一个 skill = SKILL.md（name/description 触发路由 + 指令）+ 可选 scripts/assets/references。设计时明确触发条件、输入输出、步骤、约束、验收标准。

# 1 分钟回答

- frontmatter：name、description（决定何时触发）
- 正文：步骤、约束、验收、注意事项
- scripts：可执行脚本，避免重复生成代码
- assets/references：模板与参考资料
- 设计要点：职责单一、触发明确、可复用、可验证
