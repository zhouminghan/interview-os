# 一句话

重试解决偶发失败，幂等保证重跑不出重复，断点续跑让失败后只补没跑完的那段。

# 30 秒回答

重试要限次数 + 指数退避，避免把下游打挂；幂等靠确定性 ID（比如文档 URL 的 hash）做 upsert，重复执行结果不变；断点续跑按分区/批次记录处理状态，失败后从 checkpoint 继续，不从头再来。对外部写操作，至少保证 at-least-once 加下游去重，条件允许就做到 exactly-once。

# 1 分钟回答

- 重试：有限次数、指数退避，区分可重试和不可重试错误
- 幂等：唯一 key + upsert，相同输入重跑结果一致
- 断点续跑：批次级 checkpoint 记进度，失败只补增量
- 兜底：死信队列收失败记录，告警 + 人工介入
- 边界：下游不可重试时，用两阶段提交或下游去重兜底
