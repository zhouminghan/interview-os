# 一句话

四个方向：元数据自动补全、敏感数据自动识别打标、AI 代码评审、数据质量异常检测；风险是误判、元数据污染和合规问题。

# 30 秒回答

数据治理是 AI 最容易落地也最容易翻车的方向。容易落地是因为治理工作大量是「看字段名和样本数据推断含义」这类模式识别任务；容易翻车是因为治理结论一旦错了会污染下游所有依赖元数据的系统，包括 Agent 自己。

# 1 分钟回答

- 元数据自动补全：用 LLM 从字段名和样本数据推断业务含义，补齐表/字段注释
- 敏感数据识别与打标：自动发现手机号、身份证、地址等，支撑脱敏和权限策略
- AI 代码评审：规范检查、性能风险（如全表扫描、小文件）、重复建表检测
- 数据质量异常检测：对比历史基线识别突增突降、分布漂移
- 风险一：元数据补全结果未审核直接上线，会污染血缘和 Agent 取数
- 风险二：敏感数据漏判带来合规风险，训练数据不能泄露用户敏感信息
- 风险三：告警风暴，把业务正常波动判成异常
