# 一句话

ChatBot 是对话外壳，RAG 是给模型补知识的检索技术，Agent 是能自主规划并调用工具完成目标的闭环系统；三者是层层叠加，不是互斥。

# 30 秒回答

这三者的关系常被答反。RAG 解决「模型不知道」，Agent 解决「模型不会做」，ChatBot 只是交互形态。一个成熟的问数产品通常三者都有：ChatBot 形态 + RAG 补口径知识 + Agent 做规划、调工具、自检和反馈。

# 1 分钟回答

- ChatBot：以对话为交互形式，本身不承诺自主性和工具调用
- RAG：检索增强生成，解决知识时效和私有知识问题；流程是切分 → 向量化 → 存储 → 检索 → 重排 → 生成
- Agent：有目标、能规划（Plan）、能调用工具（Tool Use）、能根据结果迭代（Agent Loop）、能决定何时结束
- 关系：RAG 可以是 Agent 的一个工具；Agent 可以包在 ChatBot 里
- 评测差异：普通问答评测看答案正确性，Agent 评测还要看过程（工具调用是否正确、步骤是否有效）
