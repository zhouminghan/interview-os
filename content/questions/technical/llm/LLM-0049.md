# 一句话

ES/向量索引 + 权限过滤 + 时间范围，多租户用租户字段隔离，大客户独立索引。

# 30 秒回答

数据接入 ES 建倒排 + 向量索引，查询时权限过滤和时间裁剪；多租户按租户 ID 隔离，大客户单独部署避免互相影响。
