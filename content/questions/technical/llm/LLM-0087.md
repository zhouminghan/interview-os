# 一句话

structured output 是让模型按固定 schema（如 JSON）输出，便于程序解析；靠 JSON mode、function calling、约束解码控制。

# 30 秒回答

在 prompt 里给 JSON 模板 + 字段说明，或用 JSON mode / function calling 强制模型按 schema 输出，再加约束解码从 token 层面保证格式合法，最后做校验兜底。

# 1 分钟回答

- 定义：固定 schema 的结构化输出（JSON/XML）
- 控制手段：prompt 给模板、JSON mode、function calling 传参、约束解码
- 好处：程序可解析、下游稳定、减少二次解析错误
- 兜底：输出后 schema 校验，失败重试
