# 一句话

RAG 解决「知识注入 + 时效」，不改模型权重；微调改变模型行为/风格/领域能力。SFT 学格式和任务快，RLHF 对偏好、安全、对齐更稳。

# 30 秒回答

RAG 适合外部知识频繁更新、要可追溯；微调适合固定领域知识、特定输出风格。SFT 用标注数据监督学格式快、易迭代；RLHF 用人类偏好训练奖励模型对齐，更稳但成本高。

# 1 分钟回答

- RAG：知识外置、时效强、可溯源，不改权重
- 微调：领域能力、风格固化，要训练数据和算力
- SFT：快速学格式/任务，标注成本可控
- RLHF：对齐偏好/安全，效果好但成本高、不稳定
- 破局点：基模越来越强，SFT 重点在差异化格式，RLHF 在安全对齐和长尾偏好
