# 一句话

七步：采集 → 合规过滤 → 清洗去重 → 增强 → 标注 → 划分 → 入库管理，每一步都要卡质量。

# 30 秒回答

原始采集（Kafka 实时 + Spark 全量回灌）→ 合规过滤（版权/违规/隐私脱敏前置）→ 清洗去重（SimHash/MinHash 相似度去重 + 低质过滤 + 格式统一）→ 数据增强（同义改写/回译/模板构造）→ 标注（人工 + 自动，双盲 + Kappa）→ 划分（训练/验证/测试，防穿越）→ 入库（版本 + 元信息 + 血缘）。

# 1 分钟回答

- 采集：笔记标题正文、配图描述、评论，实时 + 离线回灌
- 合规：版权、违规、隐私脱敏必须前置
- 清洗去重：相似度去重、低质过滤、格式统一
- 增强：同义改写、回译、Prompt 模板化构造配对
- 标注：人工 + 自动，双盲校验 + Kappa 系数验收
- 划分：训练/验证/测试按时间或分层抽样，严防穿越
- 入库：版本号 + 元信息 + 血缘
- 迁移点：清洗去重、合规、入库这几步和离线数仓 ODS→DWD 本质一致，可直接迁移
