# 一句话

Agent 全流程是「解析意图 → 匹配 Skill → 加载上下文 → 调 MCP 工具 → 输出 + 人工审核」，其中 MCP 是「手」负责执行，Skill 是「脑」负责编排。

# 30 秒回答

用户输入诉求 → Agent 识别关键词匹配 Skill → Skill 加载知识库上下文 → 按 SOP 顺序调 MCP 工具查元数据/建任务/查分区 → 输出结构化结果给人工审核。MCP 提供执行能力，Skill 编排「什么场景、什么顺序、调哪些工具、加载哪些上下文」。

# 1 分钟回答

- 用户输入：DE 在 IDE 提诉求，如「回溯源表 5 月 10 号数据」
- 意图解析：Agent 识别「回溯」关键词触发数据回溯 Skill
- Skill 加载：Skill 本质是 SOP 配置（触发词 + 步骤 + 上下文 + 工具调用顺序）
- 上下文准备：加载业务知识库、表元数据作为 Prompt 上下文
- MCP 调用：按顺序调「血缘查询」「分区查询」等工具
- 输出 + 审核：生成结果给 DE 审核，关键操作人工确认
- 分工：MCP=手（执行）、Skill=脑（编排）、知识库=记忆（上下文）
