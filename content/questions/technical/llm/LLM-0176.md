# 一句话

多轮消歧靠上下文补全和澄清追问，强弱意图按置信度分级处理。

# 参考回答

多轮对话里消歧先把省略的主语、条件从历史上下文补全，补不回来就主动澄清追问。强意图和弱意图按置信度分：明确的指令直接执行，模糊的就降级成澄清或给候选让用户确认。核心是上下文管理和置信度分级，别把弱意图当强意图执行错了。
