# 一句话

Kafka 做削峰、解耦、重放；Redis 做高频读写缓存；两者串联成「线上服务 → Kafka → Flink → Redis/HDFS」的实时样本回流链路。

# 30 秒回答

Kafka 三件事：削峰（行为流高峰缓冲）、解耦（上游写一份多消费组各取所需）、重放（从任意 offset 重消费）。Redis 三件事：用户 Embedding 毫秒级查询、Flink 算完的实时特征写入给线上读、样本去重用 SET 做短窗口过滤。

# 1 分钟回答

- Kafka：源头的削峰/解耦/重放，按主框架/模块拆 Topic
- Redis：Embedding 缓存给线上推理、实时特征写缓存、样本去重短窗过滤
- 完整链路：线上服务 → Kafka → Flink 实时打标 → 双路出口（一份进 HDFS/Iceberg 给离线训练，一份进 Redis 给在线学习）
- 关键：Redis 不是持久层，HDFS/Iceberg 才是真值来源
