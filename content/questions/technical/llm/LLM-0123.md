> **来源面经**：科大讯飞-大数据工程师实习-20260514 Q5

这道题表面问"用过什么"，**实际在测两件事**：① 你对 AI 趋势是否有真切感知（不是只听过名字）；② 你在 AI 时代是否有自驱学习能力。**讯飞、字节、阿里这些 AI 厂或 AI 重度公司必问**。

我把用过的产品分两类讲——**AI Coding Agent（主战场）** 和 **日常通用 LLM**。

### 一、AI Coding Agent（DE 工作主战场）

| 产品 | 厂商 | 我的使用场景 | 评价 |
|---|---|---|---|
| **腾讯 CodeBuddy** | 腾讯 | 主战场——基于它做 Skill 工作流开发，覆盖建模、回溯、出库、知识生成 | 内网集成好，MCP 接入腾讯数据平台（US/WeData/OLA）打通了数据开发全链路 |
| **Claude Code** | Anthropic | 同源对比，长上下文+复杂任务质量好 | Skill / Agent / MCP 这套范式的开创者，定义了行业标准 |
| **Cursor** | Anysphere | 前端同事用得多，简单场景试过 | IDE 集成好但 Agent 能力相对弱，更偏"AI 补全"而非"AI 完成任务" |
| **GitHub Copilot** | GitHub | 早期试过 | 已被 Cursor / Claude Code 这种 Agent 范式甩开，主要做代码补全而非任务执行 |

### 二、日常通用 LLM

| 产品 | 厂商 | 适用场景 | 我的评价 |
|---|---|---|---|
| **Kimi** | 月之暗面 | 长文档（PDF / 论文 / 200K 上下文） | 中文长上下文做得最好的国产模型 |
| **豆包 / 元宝** | 字节 / 腾讯 | 临时查问题、翻译、闲聊 | 国产对话流畅度高，免费易用 |
| **DeepSeek** | DeepSeek | 推理类问题、代码 | 开源里推理能力最强，性价比天花板 |
| **ChatGPT** | OpenAI | 技术方案对比、写英文 | 通用能力第一梯队，但访问受限 |
| **Claude（网页版）** | Anthropic | 长文本生成、复杂逻辑梳理 | 写作和长文档处理质量最好 |

### 三、个人观察与判断（加分项）

**1. AI Coding 的范式演进**——从 Copilot（补全）→ Cursor（IDE Agent）→ Claude Code / CodeBuddy（终端 Agent + Skill + MCP）。**未来 1-2 年的方向是 Agent 自主完成任务**，DE 的角色从"写代码"转向"审核方案"。

**2. 通用 LLM 的差异化**——大模型本身能力差距在收敛，**真正的差异化在生态（MCP / 插件 / 上下文工程）**。这也是为什么大厂都在做自己的 Agent 平台。

**3. 评价一个 AI 产品好不好的标准**——我会从三个维度看：
- **任务完成度**（能不能真把活干完，不是聊得好）
- **稳定性**（同一个任务反复跑结果是否一致，做 Skill 必须考虑这个）
- **可控性**（出错时能不能定位、能不能干预，黑盒产品落地不了生产）

### 四、用产品 vs 做产品

我现在不只是"用大模型"，更多是在**基于大模型做 Skill 开发**：研究 Prompt 工程、上下文构造、MCP 工具链编排、自检规则设计。这块我做了一年多，沉淀了一套"Agent + MCP + 知识库"的提效方法论。

**这是面试 AI 厂时的最大加分点**——光列产品名是用户视角，能讲出"我怎么基于它做工程化"才是工程师视角。

> 💡 **专家补充**：
> - **回答这题的隐藏分在"产品观点"上**——光列名字面试官打不出高分，每个产品至少给一句你自己的评价（哪强哪弱），立刻显示出你是真用过、真思考过
> - **AI 厂面试一定要带"国产大模型"列表**——讯飞、字节、阿里、腾讯都有自己的大模型，**只列 ChatGPT/Claude 不列国产模型会被认为脱节**。同时要避免无脑捧国产或无脑捧国外，给客观评价
> - **\"AI Coding Agent\"现在是个非常时髦的赛道**——能讲清 Cursor / Claude Code / CodeBuddy 这几款产品的差异（IDE vs 终端、补全 vs Agent、国产 vs 国外），立刻和"只用过 ChatGPT"的候选人拉开差距
> - **MCP（Model Context Protocol）是 2025 年最重要的 AI 工程协议**——Anthropic 提出后被各大厂迅速跟进。能在面试中主动讲 MCP 的设计哲学（标准化 AI 与外部系统交互），就能体现技术敏感度
> - **\"用产品\"和\"做产品\"是两个段位**——P5/P6 答得出"我用过哪些"，P7+ 答得出"我基于产品做过哪些工程化"。校招/实习面试官**听到候选人主动讲 Skill 开发、Prompt 工程，往往会眼前一亮**
