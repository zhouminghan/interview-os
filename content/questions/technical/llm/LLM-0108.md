> **来源面经**：京东JDY-一面-20260415 Q9、字节跳动-交易与广告-20260415 Q24

几个方向：
1. **模板化 SQL 生成**：数仓里套路相似的 SQL 逻辑（位图 UV、DIDF 关联）交给 AI Skill 自动生成，效率提升 6 倍
2. **运维自动化**：数据回溯、出库任务创建、表知识文件生成这些重复操作通过 MCP 直接完成
3. **知识库辅助**：新人理解业务时直接问 AI，基于知识库回答表结构和口径问题
4. **代码审查**：帮忙检查 SQL 性能问题

**不适合的场景**：需求理解、口径对齐、架构决策这些需要强业务判断力的，AI 目前做不好。
