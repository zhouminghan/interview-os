# 30 秒回答

问题 -> 意图识别 -> 指标/口径解析 -> 检索（知识库/元数据）-> SQL 生成 -> 校验/权限 -> 执行 -> 结果 -> 反馈。核心是语义层把业务意图映射到指标和表。

# 1 分钟回答

- NLU：意图、实体、指标识别
- 语义层：指标字典、口径、维度映射
- 检索：RAG 召回业务定义和元数据
- SQL 生成：结合 schema 生成查询
- 校验：语法、权限、口径
- 执行 + 反馈：执行、结果、评测迭代
