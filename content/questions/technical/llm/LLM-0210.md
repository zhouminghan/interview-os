# 一句话

高风险动作留人工卡点，其余靠「可验证的完成条件 + 事后审计」闭环；不能只看模型说「做完了」。

# 30 秒回答

无人值守最大的坑是把模型的自述当完成信号。正确做法是在下发任务时就定义好机器可判定的完成条件（产物存在、行数符合预期、对账通过、状态已提交），由系统去验，模型只负责汇报。

# 1 分钟回答

- 完成条件：任务下发时定义可机器验证的断言（产物、记录数、对账、状态位）
- 验证：执行器独立核验，不采信模型自述；抽样回查关键结果
- 人工确认保留在：写操作、删除、权限变更、发布上线、对外输出、超阈值成本
- 权限与审计：最小权限、只读优先、全链路留痕可回放
- 异常兜底：超时/反复失败自动降级并告警，不允许静默吞掉失败
- 成本闸门：单任务 Token / 时长上限，超限转人工
