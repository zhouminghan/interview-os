# 回答思路

1. 开口先说清洗从可执行的标注规范开始，只有先定义什么算脏数据、什么算好样本，规则才有依据。
2. 接着讲数据链路：记录来源、去重、格式归一、脱敏和训练/测试泄漏检查，再抽样看分布。
3. 然后处理标注不一致：让样本独立多标注，用一致性指标和逐标签混淆找出分歧，再修订规范并仲裁难例。
4. 最后补边界：低一致性不等于「标注员不行」，多数投票也不能掩盖任务本身有歧义；测试集不参与规则选择，数据集与规范要留版本。

# 一句话

训练数据清洗是规则、统计检查和人工复核组成的可追溯流程；标注不一致要先定位规范模糊或样本歧义，再用一致性指标、仲裁和指南迭代解决。

# 30 秒回答

我不会把清洗说成跑几条正则。先要有清楚的标注规范和数据来源记录，再做精确/近似去重、格式归一、敏感信息处理和训练测试泄漏检查。明显脏样本可以用规则或小模型筛出来，但删除前要抽样复核。遇到标注分歧，先让多个标注员独立标一批样本，用 Kappa 之类的一致性指标和标签混淆定位问题，再决定是改指南、仲裁，还是把真正含糊的样本单独处理。

# 1 分钟回答

第一，搭清洗链路：保留来源、授权与版本，先按精确和近似重复做去重，再统一编码、长度和格式，处理个人信息与敏感内容；划分训练/验证/测试集之前就要排除近似重复和测试泄漏。第二，处理分歧：用双人或多人的独立标注计算协议一致性，两名标注员可用 Cohen's Kappa，多人可用 Fleiss' Kappa 或 Krippendorff's alpha；按标签看混淆矩阵，区分指南不清、样本本身多义和个人误标，随后修订指南、用 gold set 校准标注员并由专家仲裁。第三，补落地边界：主动学习可优先送模型不确定且有代表性的样本去人工复核，但不能用多数投票抹平系统性歧义；持续多义的样本应新增「无法判断」类或剔除，清洗规则只在验证集上评估，固定数据快照，测试集始终不参与规则选择和阈值调优，避免规则迭代间接看过测试标签。

# 追问

- Kappa 低说明什么？回答要点：它是扣除偶然一致后的标注一致性，低值可能来自指南不清、标签边界重叠或样本本身有歧义，应结合逐标签混淆定位，而不是直接归咎于标注员。
- 主动学习为什么能减少标注成本？回答要点：把预算优先给模型不确定且有代表性的样本，提高每批人工标签的信息量；前提是标注规范稳定，并持续抽查被筛掉的样本。
- 怎么防止清洗引入数据泄漏？回答要点：先做跨集合的精确/近似去重，隔离测试近似样本，清洗规则和阈值只基于训练/验证集确定，并保留测试集、规范与数据快照的版本记录。
