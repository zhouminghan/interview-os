> **来源面经**：字节跳动-交易与广告-20260415 Q25

Agent 是一个具备理解和推理能力的智能体，能根据用户意图判断该做什么、怎么做。Skill 是特定领域的能力插件，定义了完成某个具体任务的标准化工作流——输入什么、走什么步骤、调什么工具、输出什么格式。

两者的关系类似**操作系统和应用**：Agent 负责理解意图和调度，Skill 负责具体执行。

比如我说"帮我回溯 xxx 表最近 7 天"，Agent 识别出要用"数据回溯 Skill"，然后按 Skill 定义的流程执行——查依赖、检查分区、输出报告。Skill 保证了执行结果的一致性和稳定性。

目前的架构是**单 Agent + 多 Skill 模式**，不是多 Agent 协作，因为场景还没复杂到需要多 Agent 的程度。
