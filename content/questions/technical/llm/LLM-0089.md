# 一句话

主 Agent 拆解任务、编排子 Agent、汇总结果；子 Agent 负责专项；通信靠结构化消息，异常靠超时、重试、降级和人工兜底。

# 30 秒回答

主 Agent 做规划/分发/汇总，子 Agent 做执行，之间用结构化消息传递上下文和结果。异常处理：超时重试、失败降级到备用方案、结果校验、关键步骤人工确认。混合路由按任务难度分派不同模型，限流器控并发防过载。

# 1 分钟回答

- 主从分工：主 Agent 规划编排，子 Agent 专项执行
- 通信：结构化消息，明确输入输出 schema
- 异常：超时、重试、降级、校验、人工兜底
- 混合路由：简单任务用小模型，复杂任务用大模型，省成本
- 限流：控制并发，防多 Agent 把外部 API/资源打爆
