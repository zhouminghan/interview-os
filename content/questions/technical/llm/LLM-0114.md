> **要点提纲**：事件化采集 | JSON解析 | 工具调用日志结构化 | 调用链路分析 | 反哺策略优化
> **来源**：字节-AI Agent数据开发-20260420 Q18

AI Agent 的工具调用数据本质上是结构化日志。采集上，Agent 每次调用工具时，服务端埋一条标准化事件日志，包含核心字段：session_id、turn_id、tool_name、tool_input（参数）、tool_output（返回值）、latency、status（成功/失败）、timestamp。

解析方面，工具调用的 input/output 通常是嵌套 JSON，需要展开成扁平化字段。不同工具 output 结构不同，DWD 层按工具类型分表或用通用字段+扩展 JSON 列存储。

存储策略：原始日志走 Kafka 进入数据湖全量保留，DWD 层做结构化清洗，DWS 层按工具维度做聚合统计（调用次数、成功率、平均耗时）。

分析维度：工具调用分布（哪些工具最常用）、调用成功率和失败原因分析、工具链路调用顺序（一个请求触发了哪些工具、什么顺序）、延迟分析（哪个工具是瓶颈）。分析结果可以反哺 Agent 的工具选择策略优化。
