# 一句话

精确哈希 + 感知哈希（图像）+ embedding 语义去重，分层组合。

# 30 秒回答

精确哈希去完全重复，感知哈希（pHash/dHash）去近似重复，embedding 向量做语义去重，兼顾准确和规模。
