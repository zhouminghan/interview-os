# 一句话

给对上下文（表结构/口径/关系）+ 约束输出（Schema Linking/Few-shot）+ 校验反馈。

# 30 秒回答

语义层提供表结构、字段含义、口径；用 Few-shot 和 Schema Linking 先定位表和字段再生成；生成后校验字段存在性、聚合正确性、语法，错误反馈修正。
