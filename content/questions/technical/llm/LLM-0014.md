# 一句话

用同一测试集做前后对比，控制变量，分维度评测，注意统计显著性和测试集不泄漏。

# 30 秒回答

固定测试集，优化前后各跑一遍，对比准确率/通过率；分层看意图、召回、回答质量；用人工评审 + 自动指标交叉验证，避免测试集泄漏。

# 1 分钟回答

- 控制变量：同一测试集、同一评测标准
- 分维度：意图识别、召回、回答质量
- 交叉验证：自动指标 + 人工抽检
- 显著性：样本足够、不是偶然波动
- 防泄漏：测试集不参与优化
