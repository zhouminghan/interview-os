# 一句话

先确认是模型还是数据，再沿「数据量 → 质量 → 分布 → 特征 → 标签」链路逐层排查，同时先回滚止血。

# 30 秒回答

排查链路：先看监控定位模型效果下跌时间点 → 确认是否伴随样本/特征变更 → 查数据量（骤降/缺失）→ 查质量（空值/重复/异常）→ 查分布（PSI 漂移）→ 查特征对齐（穿越）→ 查标签（标注一致性）。应急方案：先回滚到上一版样本/模型止血，再定位根因。

# 1 分钟回答

- 定位时间点：模型效果从哪一刻开始跌
- 关联变更：那前后有没有样本、特征、上游表变更
- 数据量：样本量骤降、分区缺失
- 数据质量：空值、重复、格式异常
- 分布漂移：训练集 vs 线上流做 PSI，超阈值说明分布变了
- 特征对齐：线上是否用了训练时拿不到的数据（穿越）
- 标签：标注规则变了、标注一致性下降
- 应急：先回滚止血，再复现根因，最后加监控防复发
