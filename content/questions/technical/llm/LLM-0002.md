# 一句话

tools 参数告诉模型有哪些工具，messages 承载对话上下文；框架解析模型返回的 tool_calls、执行工具、把结果回填并继续请求。

# 30 秒回答

请求里 messages 是完整对话，tools 是工具 JSON Schema（name/description/parameters）。模型返回 tool_calls 后，框架执行对应函数，把结果以 role=tool 追加进 messages，再次调用模型，直到 stop。

# 1 分钟回答

- tools 参数：描述工具能力、参数类型，模型据此决定调用
- messages：system/user/assistant/tool 四类角色
- tool_choice：可 auto / none / 指定工具，控制是否强制调用
- 框架循环：解析 tool_call -> 执行 -> 回填 -> 再请求 -> 直到 stop
- 代表：OpenAI SDK、LangChain、Agent 框架
