# 一句话

清洗分三步：抽正文、过滤低质页、去重，目标是让进 embedding 的都是高质量、不重复的正文。

# 30 秒回答

先解析 HTML 抽正文，去掉导航/广告/脚本；再按规则或分类器过滤垃圾页（空页、爬虫页、营销页、过短页）；最后用 MinHash/SimHash 做近重复去重，配合 URL 和正文精确 hash 兜底。低质过滤和去重要放在 embedding 之前，否则垃圾会污染向量库还浪费算力。

# 1 分钟回答

- 抽正文：HTML 解析，去导航/广告/脚本/弹窗
- 低质过滤：空页、超短页、营销页、机器生成页，规则 + 分类器
- 精确去重：URL/正文 hash 去完全重复
- 近重复：MinHash/SimHash，网页转载、小改动也能识别
- 语义去重：相似内容不同措辞，可选，成本高
- 顺序：清洗去重前置，先保证进 embedding 的数据干净
