# 一句话

AI Agent 依赖四类数据基础设施：数据接入/治理、向量检索、元数据/知识库、评估监控与权限。

# 30 秒回答

底层要高质量数据（采集/清洗/治理）、向量库做语义检索、元数据+知识库做上下文、评估监控做效果度量，外加权限和血缘。数据工程师不会被淘汰，而是从「写报表」转向「建设 AI 可用的数据底座」。

# 1 分钟回答

- 数据接入治理：清洗、去重、标注、质量控制
- 向量检索：Embedding + 向量库做 RAG
- 元数据/知识库：表结构、口径、血缘作为 Agent 上下文
- 评估监控：准确率、召回、可观测性
- 权限安全：全链路校验
- 数据工程师角色：从报表建设转向 AI 数据底座建设，是升级不是淘汰
