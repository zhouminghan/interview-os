> **要点提纲**：prompt模板拆分 | 上下文窗口管理 | token计数 | 版本管理 | 结构化存储
> **来源**：字节-AI Agent数据开发-20260420 Q19

prompt 数据结构化处理关键是拆分和版本化。一个完整 prompt 通常包括 system_prompt（系统指令）、few_shot_examples（示例）、user_input（用户输入）、context（上下文注入）。存储时拆分成独立字段——这样才能分析哪部分 prompt 变更导致了效果变化。

上下文数据的处理核心是管理好 token 预算。每次请求的上下文包含历史对话、检索结果、工具返回等，需要记录每部分占用的 token 数。DWD 层存储应记录 total_tokens、prompt_tokens、completion_tokens，以及各部分上下文的 token 占比。

结构化存储方案：用宽表存储每次 LLM 调用的完整信息——request_id、session_id、model_version、system_prompt_version、user_input、context_summary、total_tokens、latency、output_text。prompt 模板做版本管理，每次变更记录版本号，方便后续做 A/B 实验分析不同 prompt 版本对效果的影响。
