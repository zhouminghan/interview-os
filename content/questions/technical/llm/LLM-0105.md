> **来源面经**：腾讯-数据工程-20260415 Q23

MCP（Model Context Protocol）是让 AI 调用外部工具的标准协议。我们把内部平台 API 封装成 MCP 工具注册到 CodeBuddy。

**出库任务创建的调用链路**：
1. 触发"出库任务 Skill"，输入目标表名
2. AI 通过 MCP 调用**元数据查询接口**，拿到字段和分区信息
3. 根据字段信息自动生成出库配置（源表字段 → MySQL 目标字段映射）
4. 通过 MCP 调用**任务创建接口**，在 US 调度平台创建出库任务
5. 返回任务链接给我确认

以前手动填十几个配置项约 15 分钟，现在 2 分钟搞定。

**我的角色**：配合正式员工对接内部平台 API，调试接口参数，确保 MCP 工具返回的数据格式和 Skill 预期一致。
