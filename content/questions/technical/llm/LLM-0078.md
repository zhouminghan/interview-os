# 一句话

特征就是模型输入；对齐的核心是统一口径、统一计算逻辑、统一时间戳，避免「特征穿越」和离线/线上不一致。

# 30 秒回答

特征从用户（画像/长期偏好/活跃度/社交关系）、内容（品类标签/统计指标/时效/作者）、行为（实时序列/交叉行为）三维度构建。离线线上对齐靠四点：统一口径（一份特征一个定义）、统一计算（抽 SDK 或 Feature Store 双端共用）、统一时间戳（训练样本取请求时刻快照）、定期抽样对比差异告警。

# 1 分钟回答

- 特征维度：用户（静态画像/长期偏好/活跃度）、内容（标签/CTR 点赞率/时效/作者）、行为（最近 N 次点击序列/用户×品类偏好矩阵）
- 对齐难点：业内叫「特征穿越」，线上用了训练时拿不到的未来数据
- 统一口径：一份特征只有一个定义
- 统一计算：抽 SDK 双端共用或用 Feature Store
- 统一时间戳：训练样本取请求时刻快照，不用未来数据
- 定期抽样：对比离线 vs 线上同一特征值，差异超阈值告警
- 不一致最常见原因：时间戳没对齐，其次是特征版本不一致
