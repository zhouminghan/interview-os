# 一句话

文本用 MinHash/SimHash 近重复 + 语义去重，行为序列用特征指纹 + 序列相似度去重。

# 30 秒回答

文本：精确哈希去重 + SimHash 近重复 + embedding 语义去重。行为序列：按用户+会话+特征做指纹去重，考虑时序和序列相似度，避免简单哈希误杀。

# 1 分钟回答

- 文本：MinHash/SimHash、embedding 语义、编辑距离
- 行为序列：会话切分、特征指纹、序列相似度
- 差异：文本重语义，序列重时序和模式
- 目标：去重不伤分布，保留多样性

- 语义去重怎么做？
- 序列去重为什么不能只哈希？
