# 一句话

IDE Agent 是通用编码提效工具，解决「写代码快」；自研 Agent 是绑定业务上下文和权限边界的系统，解决「按我们的规范和口径把事做对」。

# 30 秒回答

两者常被混为一谈，但定位完全不同。IDE Agent 强在通用代码生成和重构，它在你本地上下文里工作；自研 Agent 强在接入企业内部系统（元数据、调度、权限、审批），能把业务规则固化进去。企业真正需要的是后者，但成本和技术门槛高得多。

# 1 分钟回答

- IDE Agent：通用、开箱即用、提效明显；不感知企业元数据、口径和权限
- 自研 Agent：可接入元数据知识库、调度平台、权限系统、审批流；行为可控可审计
- 本质区别：是否绑定企业业务上下文与治理约束
- 选型考虑：任务通用度、是否需要权限管控、是否有可复用的语义层、长期维护成本
- 风险：用 IDE Agent 生成的代码容易让系统架构偏离原设计，需要 Review 卡点
