> **来源面经**：阿里系-AI数据工程师两面-20260521 集团1-Q9

这三个是 AI Agent 工程的三个层次，从浅到深：

**1. 提示词工程（Prompt Engineering）—— 最浅层**

- **定义**：设计 LLM 输入的文本（Prompt），引导 LLM 输出期望结果
- **核心技巧**：角色设定（"你是资深 SQL 专家"）、Few-shot 示例、思维链（CoT）、结构化输出（JSON Schema）
- **代表方法**：Zero-shot、Few-shot、Chain-of-Thought、ReAct、Self-Consistency
- **工程化程度**：低（更像"调参"）

**2. 上下文工程（Context Engineering）—— 中间层**

- **定义**：管理 LLM 的**上下文窗口**——决定哪些信息进 Prompt、什么时候进、怎么压缩
- **核心问题**：
  - 上下文窗口有限（如 128K / 200K tokens），怎么塞进最相关的信息？
  - **RAG 检索召回**：从知识库召回 Top-K 相关文档拼到 Prompt
  - **上下文压缩**：长对话摘要、不重要内容裁剪
  - **记忆管理**：短期记忆（当前会话）vs 长期记忆（跨会话）
- **代表方法**：RAG、Memory（Mem0 / LangMem）、Context Compression、Cache-Augmented Generation
- **工程化程度**：中

**3. Harness 工程（Agent Harness Engineering）—— 最深层**

- **定义**：**整个 Agent 系统的工程化封装**——不只是 Prompt 和上下文，还包括工具、规划、反馈、监控、评测
- **核心组件**：
  - **Tool Use 框架**：MCP / Function Calling 标准化工具调用
  - **任务规划器**：ReAct / Plan-and-Execute / Reflexion
  - **失败重试 + 容错**：Agent 失败时怎么 fallback
  - **可观测性**：每一步推理的 trace、性能 metric、错误日志
  - **评测体系**：accuracy、latency、成本
- **代表项目**：Claude Code、Cursor、AutoGPT、LangGraph
- **工程化程度**：高（接近软件工程）

**三者的关系**（包含关系）：

```
Harness 工程（系统层）
  └── 上下文工程（数据层）
        └── 提示词工程（指令层）
```

**类比**：
- 提示词工程 = 写一句好 SQL
- 上下文工程 = 设计一个好查询的执行计划
- Harness 工程 = 设计整套数据库系统（含查询优化器、缓存、监控）

**项目里的对应**：
- 我写 Skill 里的 Prompt 模板 → **提示词工程**
- Skill 调用知识库做 RAG，把相关表元数据拼到 Prompt → **上下文工程**
- Skill 整个工作流（含 MCP 工具、DE 审核、失败重试、效果监控）→ **Harness 工程**

**回答模板**：「这三个是 AI Agent 工程从浅到深的三个层次——**提示词工程**最浅，调 Prompt 引导 LLM；**上下文工程**中间层，管理 LLM 上下文窗口（RAG、记忆、压缩）；**Harness 工程**最深，是整个 Agent 系统的工程化封装——含工具、规划、容错、可观测、评测。Claude Code、Cursor 这类成熟产品本质都是 Harness 工程的代表。」

> 💡 **专家补充**（AI 工程师视角，面试中视情况展开）
>
> - **「Harness Engineering」是 2025 年开始流行的概念**——之前只讲 Prompt Engineering，但发现 Agent 真正落地光调 Prompt 远远不够，整个 Harness（脚手架/装备）的工程化才是核心。Anthropic、OpenAI 内部都在用这个概念
> - **三者重要性反转的趋势**——2023 年大家都在谈 Prompt Engineering，2024 年焦点转向 Context Engineering（RAG 大火），2025 年开始转向 Harness Engineering。这是 AI 工程成熟度的标志
> - **能讲出「Harness 工程」这个词在面试官眼里是稀缺信号**——绝大多数候选人只听过 Prompt Engineering 和 RAG，能讲第三层的少。前沿大厂面试官会立刻识别出这是**真正关注 AI 工程前沿**的候选人
> - **回答时要避免「概念堆砌」**——只列名词不解释关系，会被认为是死记硬背。讲出三层包含关系 + 项目里对应的实际工作，才是高分回答
