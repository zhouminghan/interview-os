# 一句话

System prompt 定角色、规则和边界（是谁、做什么、不做什么）；few-shot 给示例让模型学会格式和风格。

# 30 秒回答

System prompt 用最高优先级设定身份、约束、输出要求，全程生效；few-shot 给几个输入→输出示例，让模型模仿格式和风格，解决「零样本不知道怎么写」的问题。

# 1 分钟回答

- System prompt：角色设定、安全边界、输出规范，优先级最高
- few-shot：示例驱动，明确期望格式和风格，适合结构化/分类任务
- 搭配：System 定框架，few-shot 定样式，两者互补
