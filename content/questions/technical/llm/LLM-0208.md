# 一句话

Agent 评测要过程与结果分开评：结果看任务完成度，过程看工具调用、步骤有效性和规划质量；没用户反馈就用真实任务集 + 专家抽检。

# 30 秒回答

普通问答评测只看答案对不对，Agent 评测还得看「怎么做到的」——一个蒙对答案但调错工具的 Agent 上线后一定出事。没有线上反馈时，用历史真实任务建评测集，按难度分层，再辅以人工抽检过程轨迹。

# 1 分钟回答

- 结果指标：任务完成率、结果正确率、端到端耗时与成本
- 过程指标：工具选择正确率、参数正确率、无效步骤占比、重试次数
- 规划能力：任务拆解合理性、是否识别信息不足并澄清、遇阻能否改道
- 幻觉率：结论是否有事实引用、是否引用了不存在的工具或字段
- 缺反馈时：真实历史任务建集分层统计 + 过程轨迹人工抽检 + Bad Case 回流
- 权衡：提高规划自由度通常抬升幻觉率，用「执行边界 + 事实引用 + 低置信拒答」把幻觉锁在可控范围
- 防回归：每次发版前跑评测集，线上纠错自动补进集合

# 追问

- 评测集怎么覆盖长尾任务？
