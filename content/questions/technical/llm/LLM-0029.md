# 一句话

从口径统一和异常识别入手，把传统校验规则 + LLM 语义理解结合。

# 30 秒回答

先用 LLM 做口径文档语义对齐（最大痛点），再做异常模式识别、校验规则生成、对账异常摘要、自动补规则，叠加传统四性校验。

# 1 分钟回答

- 口径统一：LLM 对齐指标口径
- 异常识别：LLM 识别数据波动和异常模式
- 规则生成：从文档/需求自动生成校验规则
- 对账摘要：异常结果自动归纳
- 基础：完整性/一致性/准确性/及时性
