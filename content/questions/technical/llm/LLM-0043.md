# 一句话

用段位/胜率/操作指标等规则 + 模型打分定义和筛选高质量，分层使用避免低端数据拉低上限。

# 30 秒回答

高质量 = 高段位 + 高胜率 + 职业选手标签 + 对局质量评分。规则过滤 + 指标阈值 + 模型打分 + 人工抽检；高质量做 SFT 上限，低质量做预训练或负样本。

# 1 分钟回答

- 定义：段位、胜率、KDA、操作指标、职业标签
- 筛选：规则 + 阈值 + 模型打分 + 抽检
- 分层：高质量上限数据、低质量底噪/负样本
- 目标：不拉低模型上限，保持分布多样性
