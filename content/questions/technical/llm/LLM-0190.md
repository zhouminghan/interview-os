# 一句话

核心能力是指标识别、口径确认、SQL 生成；价值是降门槛、统一口径、自动巡检；难点是口径歧义、权限风险、复杂计算，靠分层校验和人工复核兜底。

# 30 秒回答

数据 Agent 通过语义理解、知识检索和工具调用，降低数仓用数门槛。它的价值点很明确：减少开发排期、统一口径、自动巡检。但落地时最大难点不是技术实现，是口径歧义和权限风险——同一个「新客」在不同部门定义不同，Agent 一旦取错就是批量错误。所以必须做分层校验、黑白名单和人工复核。

# 1 分钟回答

- 核心能力：指标识别、口径确认、SQL 生成、自动巡检
- 业务价值：减少开发工作量、统一口径、自动数据质量巡检
- 落地难点：口径歧义、权限风险、复杂计算（多表复杂建模 Agent 做不了）
- 应对：分层校验、黑白名单、高危操作人工复核
- 边界：适合简单指标开发、临时取数、常规报表、质检规则生成；复杂大促链路仍需人工主导
