# 一句话

准确率、通过率、任务成功率、指令遵循率是核心，再叠加延迟、成本和 badcase 率。

# 30 秒回答

量化指标：准确率/通过率、任务成功率、指令遵循率、召回率、badcase 率、失败分类；成本侧看延迟、token 成本。

# 1 分钟回答

- 效果：准确率、通过率、任务成功率、指令遵循率
- 质量：badcase 率、失败原因分布、回归通过率
- 成本：延迟、token 消耗、单位任务成本
- 分层：意图识别、工具调用、最终结果分别评测
