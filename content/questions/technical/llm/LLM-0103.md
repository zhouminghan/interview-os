> **来源面经**：腾讯-数据工程-20260415 Q20

最大区别是**可复用性和稳定性**。

直接写 Prompt 每次要重新描述上下文和步骤，不同人写的质量参差不齐，同一任务每次结果可能不一样。

**Skill 是结构化的工作流定义**：
1. **输入**——数据回溯 Skill 的输入是"回溯表名 + 日期范围"
2. **执行步骤**——先查上游依赖表 → 逐个检查分区完整性 → 汇总成报告
3. **工具调用**——通过 MCP 调用平台 API
4. **输出格式**——标准化检查报告

任何人触发 Skill 就能得到一致的高质量结果。类比：**Prompt 是零散脚本，Skill 是封装好的函数。**

> 💡 **专家补充**：
> - **Skill 本质上是对 LLM 能力的"工程化封装"**——和软件工程里把重复代码封装成函数/类一样的道理。封装后才能测试、版本管理、团队共享，裸 Prompt 做不到这些。
> - **稳定性差异的根因是"约束程度不同"**——Prompt 给 LLM 的自由度太高，它可能走 A 路径也可能走 B 路径。Skill 通过结构化步骤把路径锁死，LLM 只需在每一步做好一件事。
> - **从 Prompt 到 Skill 的演进，本质上是 AI 应用从"原型阶段"到"工程化阶段"的标志**——能用 Prompt 快速验证想法，但要上生产就得做成 Skill。
