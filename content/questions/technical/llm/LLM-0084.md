# 一句话

核心目标是让模型稳定、准确地按预期输出；模型对措辞、顺序、示例高度敏感，所以换说法会显著改变输出质量。

# 30 秒回答

模型是「根据上下文概率生成」，不同措辞会激活不同的上下文路径。Prompt 工程就是把能稳定产出好结果的措辞、角色设定、示例、约束固化成可复用的模板，降低随机性。

# 1 分钟回答

- 目标：稳定、准确、可控地引导模型输出
- 为什么敏感：生成是概率过程，措辞/顺序/示例都会改变条件概率
- 手段：明确角色、给约束、给示例、拆步骤、指定输出格式
- 工程化：把好 Prompt 沉淀成 Skill/模板，减少逐次波动
