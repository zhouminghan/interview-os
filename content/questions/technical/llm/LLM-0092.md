# 一句话

防 Prompt 泄露（不暴露 system prompt）、工具最小权限、输入输出过滤、敏感信息脱敏、全程审计。

# 30 秒回答

不把 system prompt 当秘密但也要防注入；工具只给最小权限；对工具输入输出做过滤和脱敏；敏感操作要人确认；记录审计日志。防「用工具提示词诱导模型泄露内部规则或执行越权操作」。

# 1 分钟回答

- Prompt 泄露：不硬编码密钥，system prompt 做注入防护
- 最小权限：每个工具只授必要权限，按用户隔离
- 输入输出过滤：脱敏、拦截危险指令
- 敏感操作：人工确认 + 审计
- 数据安全：权限校验贯穿「查询到返回结果」全链路
