# 一句话

先跑通「采集接入 -> 清洗去重 -> 版本化数据集 -> 交付」的最小闭环，再逐层加标注、多模态和评测。

# 30 秒回答

第一版：接入对局数据、基础清洗去重、版本管理、简单质检、交付训练集，先证明链路能跑通；再规划多模态、标注、评测。

# 1 分钟回答

- P0：采集接入、清洗去重、版本化、交付
- P1：质量质检、标注、badcase 回流
- P2：多模态、实时、评测平台
- 原则：先闭环再扩展，优先交付价值
