# 一句话

训练数据质量靠质检规则 + 标注一致性 + 模型评估 + 人工抽检，指标看覆盖、准确、一致、及时、去重和坏样率。

# 30 秒回答

核心指标：覆盖率、准确率、一致性、及时性、去重率、标注一致率、坏样本率。手段：规则质检、自动评估、人工抽检、badcase 回流。

# 1 分钟回答

- 指标：覆盖、准确、一致、及时、去重、坏样率
- 规则：格式、范围、分布校验
- 评估：模型评测 + 标注一致性（如 Kappa）
- 回流：badcase 分类、迭代

- 标注一致性怎么衡量？
