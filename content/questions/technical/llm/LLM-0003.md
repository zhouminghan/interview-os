# 一句话

大模型通过 tools 参数里的 JSON Schema（name/description/parameters）理解工具能力，在推理时生成符合格式的 tool_call，实际执行由框架完成。

# 30 秒回答

框架只是把工具打包成 schema 传给模型；模型在训练/对齐阶段学过 function calling 的输出格式，根据工具描述判断何时用哪个工具、填什么参数，输出结构化的 tool_calls。

# 1 分钟回答

- 模型看到的是工具描述和参数 schema，不是工具实现
- description 决定模型何时选该工具、怎么填参数
- 模型输出被约束成 tool_call 格式（函数名 + JSON 参数）
- 模型本身不执行工具，只负责「决定调用」，执行和回填由框架负责
- 本质：把工具能力注入提示词，让模型学会「何时、用哪个、传什么」
