# 一句话

Prompt 是单次临时指令，Skill 是把「好 Prompt + 工具调用 + 上下文 + 自检」封装成可复用、可触发、可校验的工程化工作流。

# 30 秒回答

粒度不同（Prompt 一次性、Skill 可复用长期沉淀）、触发方式不同（Prompt 显式输入、Skill 自动匹配）、能力不同（Skill 内置工具调用/上下文/自检）、稳定性不同（Skill 输出质量稳定）。类比：Prompt 像 ad-hoc SQL，Skill 像注册成数仓任务。

# 1 分钟回答

- 粒度：Prompt 单次临时；Skill 结构化可复用
- 触发：Prompt 用户显式输入；Skill 由 Agent 识别关键词/场景自动加载
- 能力：Prompt 只靠模型自由发挥；Skill 内置工具调用、上下文加载、自检规则
- 稳定性：Prompt 输出因人而异；Skill 封装后不同人用同一个 Skill 输出稳定
- 本质：做 AI 提效的关键是把 ad-hoc Prompt 沉淀成可复用 Skill，从「个人提效」到「团队提效」
