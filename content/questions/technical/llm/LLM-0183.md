# 一句话

监控输入文档分布和 embedding 空间分布两处变化：文档层看主题/长度/来源，embedding 层看聚类中心和相似度分布。

# 30 秒回答

文档层监控主题分布、长度、来源、语言等统计量，变了说明入库内容漂了；embedding 层把新向量和基线对比，看聚类中心偏移、分布散度，或抽一批算和最近邻的平均相似度。发现漂移就回溯是哪批数据、哪个来源引起的，再决定重分块还是重建索引。

# 1 分钟回答

- 文档层：主题/长度/来源/语言分布，PSI 或直方图对比
- embedding 层：聚类中心偏移、向量分布散度、平均近邻相似度
- 触发：分布指标超阈值告警
- 定位：按批次/来源下钻，找漂移来源
- 处理：重分块、重 embedding、重建索引
- 频率：按数据更新节奏定期跑，重要来源实时监控
