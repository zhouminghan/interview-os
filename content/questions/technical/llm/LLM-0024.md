# 一句话

通常复用平台模型和工具调用能力，自研业务流程、prompt、RAG 和评测。

# 30 秒回答

复用平台通用模型和工具调用能力，自研业务 prompt、知识库检索、流程编排和评测；设计思路是意图识别 -> 检索 -> 生成 -> 校验 -> 反馈闭环。

# 1 分钟回答

- 复用：通用模型、工具调用、基础设施
- 自研：业务 prompt、RAG、流程、评测
- 设计：意图 -> 检索 -> 生成 -> 校验 -> 反馈
- 取舍：自研灵活性 vs 复用成本
