# 一句话

常见分三类：事实性幻觉（编造不存在的事实）、忠实性幻觉（偏离给定上下文）、指令违背；数据场景主要防第一类，靠知识库约束 + 引用校验 + 拒答机制。

# 30 秒回答

数据岗问幻觉，重点不在理论分类，而在「你怎么保证取数不出错」。核心思路是把幻觉从「模型层面的概率问题」转成「工程层面的可校验问题」：答案必须挂事实引用，引用不在允许集合里就拒绝输出；检索为空时明确说没有，而不是让模型编。

# 1 分钟回答

- 事实性幻觉：编造知识库里不存在的表、字段、指标——数据场景危害最大
- 忠实性幻觉：答案偏离检索到的上下文，RAG 场景常见
- 指令违背：没按要求格式或范围输出
- 校准手段一：知识库硬约束，禁止使用不存在的表和字段，不确定必须反问
- 校准手段二：结论必须挂事实引用，禁止编坐标，归因证据不可追溯就不让讲圆
- 校准手段三：置信度低时拒答或澄清，用「不会」换「不错」
- 评测：RAG 场景看 Faithfulness（忠实性）和 Answer Relevance（答案相关性）
