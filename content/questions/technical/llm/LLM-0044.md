# 一句话

用统一时间戳或游戏 tick/帧对齐，再做采样同步和质量校验。

# 30 秒回答

以游戏帧/tick 为基准统一时间戳，把操作、语音、画面按时间戳对齐；语音按时间窗、画面按帧采样；再校验对齐误差。

# 1 分钟回答

- 基准：游戏帧/tick 或统一时钟
- 对齐：按时间戳/帧索引映射
- 采样：画面按帧、语音按窗
- 校验：对齐误差、缺失检测

# 追问

- 不同模态采样率不同怎么对齐？
- 对齐误差怎么度量？
