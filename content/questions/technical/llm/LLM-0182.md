# 一句话

历史全量走离线批量，增量走实时流式，扩容按吞吐水平加 worker，瓶颈在模型推理就加 GPU 或限流排队。

# 30 秒回答

存量文档用离线批处理一次性算完；新文档/更新走实时流式，进了就生成 embedding。扩容看瓶颈：CPU 密集型加 worker 数，GPU 推理慢就加 GPU 或做批处理合并请求、限流排队削峰，热门文档缓存复用别重复算。

# 1 分钟回答

- 离线批量：历史全量、定期重建，吞吐优先
- 实时流式：增量文档即时生成，延迟优先
- 扩容：无状态 worker 水平扩，按吞吐配副本
- 削峰：批量合并请求、限流、队列缓冲
- 缓存：热门/不变文档复用结果，降本又提速
- 监控：生成延迟、队列积压、失败率

- 实时和离线结果不一致怎么办？
