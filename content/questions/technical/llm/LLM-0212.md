# 一句话

分级解决「热记忆快取、冷记忆可检索」；并发靠版本与单写者，重排按相关性/时效/可信度加权，冷启动先用规则与人工种子。

# 30 秒回答

PDD 二面把 Memory 当后端系统来问：并发、权重设计、冷启动，全是工程题。答的时候别停在「短期/长期」的概念层，要讲清存储结构、写入冲突和排序公式怎么定。

# 1 分钟回答

- 分级：L1 会话内热记忆（内存/缓存）、L2 结构化长期记忆（库表 + 索引）、L3 归档可检索
- 并发冲突：单写者 + 版本号/乐观锁，写入前做相似记忆冲突检测
- 重排三部分权重：语义相关性、时间新近度、来源可信度／被采纳次数，按业务调权并做 A/B
- 权重校准：用「历史记忆是否被正确引用」的标注集回归，避免新近度压过正确性
- 冷启动：先用人工种子规则 + 业务元数据兜底，累积足量反馈后再放开自动写入
- 降级：检索为空时明确返回无记忆，禁止模型凭空补
