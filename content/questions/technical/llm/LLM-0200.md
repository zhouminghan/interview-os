# 一句话

用真实历史问题建集，按难度分层，标注标准 SQL 和标准结果，同时看执行成功率和结果正确率两个指标。

# 30 秒回答

没有评测集就没有准确率，没有准确率就无法迭代——这是面试官判断你是否真做过智能问数的分水岭。建设要点是：题目来源必须是线上真实问题而不是人工编造；必须分层，否则整体准确率会被大量简单问题拉高；评判不能只看 SQL 是否跑通，要看结果数值是否一致（两个 SQL 写法不同但结果相同应判对）。

# 1 分钟回答

- 题目来源：线上真实提问日志 + 业务方补充，按频次取 Top N
- 难度分层：单指标查询 / 多指标组合 / 跨周期对比 / 比率与衍生指标 / 需要澄清的歧义问题
- 标注：标准 SQL + 标准结果集，口径必须由业务确认
- 指标：执行成功率（能否跑通）+ 结果正确率（数值是否一致），分开统计
- 特殊情况：SQL 写法不同但结果相同判定为正确；口径错误即使跑通也判错
- 迭代：线上答错和用户纠正的问题自动回流进评测集，发版前回归
