# 一句话

数据开发从「全流程开发者」变成「审核者 + 基建者」：AI 生成方案和代码，人做 review、纠偏、把关，并把精力转向数据治理。

# 30 秒回答

需求先丢给 Agent 生成设计文档，人 review 纠偏，确认后 AI 建表、写加工、走评审、自动上线。人不再逐字写 SQL，而是审方案、管口径、建好数据底座，让 AI 有高质量输入。

# 1 分钟回答

- 流程转变：AI 理解需求 → 生成设计文档 → 人 review 纠偏 → AI 执行 + 评审 + 上线
- 角色转变：从写 SQL 的开发者 → 审方案、管口径的审核者
- 精力转移：从取数开发转向数据治理、基建（好的数据喂 AI）
- 关键：不能让 AI 完全接管，评审和确认环节必须保留

- 哪些环节必须人把关？
- 数据治理为什么对 AI 提效更重要？
