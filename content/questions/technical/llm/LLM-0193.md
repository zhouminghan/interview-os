# 一句话

Agent 是会自主规划、循环调用工具的决策主体；Skill 是被 Agent 调用的、封装好的能力单元（含说明、脚本、资源）。

# 30 秒回答

这个问题在 2026 年的数据岗面试里出现频率很高，因为它能区分「用过 AI 工具」和「理解 AI 工程」。区别在于：Agent 有自主性——它决定下一步做什么、调什么工具、什么时候停；Skill 没有自主性，它是被调度的确定性能力包。一个 Agent 通常挂载多个 Skill。

# 1 分钟回答

- Agent：有目标、能规划、能循环（Agent Loop）、能决定调用哪个工具、能处理异常重试
- Skill：把一类任务的操作说明 + 脚本 + 资源打包，让模型在需要时按说明执行，降低每次重新推理的成本
- 关系：Agent 是调度者，Skill 是被调度者；Skill 让 Agent 的行为更稳定、更可复用
- 写 Skill 的心得：说明要具体到触发条件和输入输出，别写模糊描述；把不希望模型自由发挥的步骤固化成脚本
