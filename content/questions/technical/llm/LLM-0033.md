# 一句话

短期记忆是当前会话上下文，长期记忆是跨会话持久化；三层记忆按时效和粒度分层存储。

# 30 秒回答

短期：当前对话历史、working memory；长期：向量库 + 结构化存储跨会话复用。三层：会话内短期、项目级长期（文件/知识库）、全局长期，每层存不同粒度和时效。

# 1 分钟回答

- 短期记忆：当前轮上下文、最近 N 轮
- 长期记忆：向量检索历史 + 结构化知识
- 三层：会话层（临时）、项目层（领域知识）、全局层（通用偏好）
- 管理：压缩、摘要、检索、过期清理
