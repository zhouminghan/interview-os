# 一句话

LoRA 冻结原权重，用低秩旁路矩阵微调；Self-Attention 是 softmax(QK^T/√d)V。

# 30 秒回答

LoRA 加 A·B 低秩矩阵，只训练少量参数；Attention(Q,K,V)=softmax(QK^T/√d_k)V，QKV 由输入经不同权重投影得到。

# 追问

- LoRA 为什么省参数？
- 为什么要除以 √d？
