# 一句话

不能只比 Token 单价，要按「单次任务端到端成本 × 成功率」对比「人力工时 × 人力单价」，再算上返工和 Review 成本。

# 30 秒回答

面试官问这个，是想确认你是不是真落地过，而不是只会喊提效。真实账要这么算：一个需求用 AI 辅助，端到端成本 = 输入 Token + 输出 Token + 重试次数带来的额外消耗 + 人工 Review 与修改工时；对比基线是纯人工工时 × 人力单价。很多场景真正省的不是 Token 钱，是等待排期的时间。

# 1 分钟回答

- 口径：单任务端到端成本，含重试和人工 Review，不要只看单次调用价格
- 成功率：AI 一次做对的比例越低，重试和 Review 成本越高，提效可能被吃掉
- 上下文成本：长上下文压缩、历史摘要能显著降低 Token 消耗
- 隐性收益：缩短排期等待、降低沟通成本，这部分往往比直接省钱更重要
- 不适合 AI 的场景：复杂大促链路、跨团队重大变更，人工主导更划算
