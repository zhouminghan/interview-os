# 一句话

通过 Function Calling / Tool Use：模型输出结构化的工具调用（函数名 + 参数 JSON），应用执行工具后把结果回传，模型再生成最终回答。

# 30 秒回答

把可用工具以 name/description/parameters 描述传给模型，模型判断是否需要调用并返回 tool_call，应用执行函数，把结果作为新消息 role=tool 回填，循环直到模型输出最终答案。

# 1 分钟回答

- 输入：messages + tools 定义
- 模型决策：返回 finish_reason=tool_calls 和 tool_calls 列表
- 执行：应用按函数名和参数调用真实工具
- 回填：结果以 tool 消息加入 messages
- 循环：直到模型返回 stop 或不再调用
- 范式：ReAct（推理 + 行动）循环
