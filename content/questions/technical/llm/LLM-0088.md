# 一句话

function calling 是让模型决定「调哪个工具 + 传什么参数」去执行动作；RAG 是检索外部知识补进上下文再回答。

# 30 秒回答

function calling 解决「要做事」：模型输出结构化调用意图，程序执行工具并回传结果。RAG 解决「要知道」：先检索相关文档，把知识塞进上下文再生成。两者可组合：先 RAG 找信息，再 function calling 执行。

# 1 分钟回答

- function calling：模型识别意图 → 输出工具名 + 参数 → 程序执行 → 结果回传
- RAG：query 向量化 → 检索 → 拼上下文 → 生成
- 选型：需要查知识/事实用 RAG，需要调系统/查库/执行动作用 function calling
- 组合：Agent 常用 RAG 补知识 + function calling 调工具

- 什么时候用 function calling 不用 RAG？
- 两者在 Agent 里怎么配合？
