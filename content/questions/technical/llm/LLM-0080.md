# 一句话

把「采集 → 清洗 → 标注 → 样本产出 → 训练」串成 DAG，用调度 + 状态机 + 断点续跑 + 异常告警保证自动化可靠流转。

# 30 秒回答

每个环节是独立算子，用 DAG 串联；调度按依赖触发；每步幂等可重跑；断点续跑靠「中间结果落盘 + 状态记录」；异常分级告警，关键节点失败卡住下游。

# 1 分钟回答

- 算子化：采集/清洗/标注/样本/训练各自独立可替换
- 调度：DAG 依赖触发，上游完成才跑下游
- 幂等：每步覆盖写 + 版本号，支持重跑
- 断点续跑：中间结果落盘，失败从断点继续
- 异常告警：分级（数据量骤降、标注一致性、训练失败）
- 版本管理：样本带版本号，训练结果可追溯到样本版本
- 人工节点：标注等人工环节插入审批/流转
