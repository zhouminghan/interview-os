# 一句话

测试集规模要覆盖足够、统计可靠，分主题/难度分层；准确与否按可执行结果/关键字段/语义等价定义。

# 30 秒回答

规模从几百到几千不等，按主题、难度分层覆盖；准确判定：结果集一致、关键字段正确、语义等价，或人工按标注标准打分。

# 1 分钟回答

- 规模：覆盖度 + 统计显著性，分主题/难度分层
- 判定：结果集一致、关键字段正确、语义等价
- 标注：明确判定标准，必要时双人标注
- 持续：不断补充 badcase
