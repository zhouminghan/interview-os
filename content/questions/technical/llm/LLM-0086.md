# 一句话

上下文窗口是模型一次能处理的 token 上限；上下文腐化是长上下文中无关/噪声信息累积，导致模型忽略关键内容、输出退化。

# 30 秒回答

窗口限制能塞多少内容；腐化是塞得越长，模型越容易「迷失」在中间，抓不住重点。解决靠按需检索、摘要压缩、分层记忆，只把关键信息放进窗口。

# 1 分钟回答

- 上下文窗口：token 上限，超了要截断/压缩
- 上下文腐化：长上下文中模型对中间信息注意力衰减、噪声干扰
- 影响：丢关键事实、前后矛盾、幻觉
- 缓解：只放相关内容、摘要压缩历史、分层记忆、关键信息靠前

# 追问

- 为什么长上下文中间信息容易被忽略？
- 怎么在有限窗口放关键内容？
