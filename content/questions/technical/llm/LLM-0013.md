# 一句话

是的，典型 RAG 把文档切块、向量化、入向量库，检索 top-k 再拼进 prompt。

# 30 秒回答

文档切分 -> embedding 向量化 -> 存向量库 -> 查询时向量检索 top-k -> 拼进 prompt。也可混合全文检索、知识图谱、表格结构化。

# 1 分钟回答

- 切分：按语义/长度切块
- 向量化：embedding 模型
- 存储：向量库（FAISS、Milvus 等）
- 检索：相似度 top-k
- 增强：全文检索 + 向量混合，结构化数据走表格/图谱
