# 一句话

MCP 是协议层（标准化连接工具/资源），tool use / function calling 是模型调用工具的具体机制。

# 30 秒回答

MCP 定义客户端-服务器协议，让 Agent 统一接入各种工具和数据源；tool use 是模型输出函数调用的机制。MCP 是连接标准，tool use 是调用方式。

# 1 分钟回答

- MCP：协议，标准化工具/资源/提示接入
- tool use：模型按 schema 输出 tool_call
- 关系：MCP 提供工具，tool use 触发调用
- 价值：MCP 解耦工具集成，避免每个工具单独适配
