# 一句话

通过意图先归域、域级/表级/行级权限、指标字典隔离和 SQL 校验来阻止跨域越权。

# 30 秒回答

意图识别先归类业务域，按域路由到对应指标字典和元数据；权限做域级/表级/行级校验；生成 SQL 时校验表和字段权限，审计留痕，阻止跨域错误调用。

# 1 分钟回答

- 意图归域：先判断属于哪个业务域
- 权限：域级/表级/行级隔离
- 指标字典：按域隔离，不混用
- SQL 校验：解析后校验表和字段可见性
- 审计：记录请求和结果范围
