# 一句话

数仓从人工维护升级为 Agent 自维护，四阶段：Harness（地基规则）→ Loop（循环自纠）→ Graph（多 Agent 协作）→ 数字人，每阶段可独立验收。

# 30 秒回答

阶段 0 先建代码知识库；阶段 1 Harness：CLAUDE.md 写分层/技术栈/命名规范/建表模板/禁止清单；阶段 2 Loop：让 Agent 循环执行 + 自纠；阶段 3 Graph：多 Agent 分工协作；阶段 4 数字人。

# 1 分钟回答

- 阶段 0：代码知识库（表口径/血缘/SQL 生成）
- 阶段 1 Harness：CLAUDE.md 项目宪法（分层职责、技术栈、命名规范 `{层级}_{业务域}_{粒度}_{描述}`、建表模板、禁止清单）
- 阶段 2 Loop：Agent 循环执行 + 自纠闭环
- 阶段 3 Graph：多 Agent 编排协作
- 阶段 4：数字人（自主维护）
- 分区规范：统一 `dt`（日）/`hh`（小时）
