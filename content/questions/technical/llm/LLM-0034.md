# 一句话

渐进式加载是 skill 按需加载：先加载 name/description 做触发，命中后再加载完整指令/脚本/资产。

# 30 秒回答

先给模型所有 skill 的 name/description（轻量目录）用于判断是否触发，命中后再加载该 skill 的完整 SKILL.md、脚本和资产，避免一次塞入全部内容、节省上下文。

# 1 分钟回答

- 目录层：name/description，决定是否触发
- 正文层：完整指令，触发后加载
- 资源层：scripts/assets，按需再加载
- 收益：省 token、按需、可扩展
