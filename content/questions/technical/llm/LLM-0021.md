# 一句话

能，前提是把表结构、字段含义、指标口径作为上下文提供给 AI。

# 30 秒回答

把表的 schema、字段注释、指标口径、血缘通过 RAG 或 prompt 提供给 AI，它就能理解字段含义并生成 SQL；没有这些上下文则理解不准。

# 1 分钟回答

- 关键：提供 schema + 字段注释 + 指标字典 + 血缘
- 方式：RAG 检索元数据、prompt 注入
- 应用：NL2SQL / 问数 Agent
- 局限：复杂口径、跨表、歧义仍需校验
