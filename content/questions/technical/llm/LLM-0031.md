# 一句话

ReAct 是 Thought-Action-Observation 循环；框架分规划、工具、记忆、执行、上下文管理、评测等模块。

# 30 秒回答

ReAct 循环：思考（Thought）-> 行动（Action 调工具）-> 观察（Observation）-> 再思考，直到产出答案。框架模块：规划器、工具、记忆、执行循环、上下文管理、评测。

# 1 分钟回答

- 模块：Planner、Tools、Memory、Executor、Context、Eval
- 交互：输入 -> 规划 -> 调工具 -> 观察 -> 更新记忆 -> 循环 -> 输出
- 关键：状态管理、上下文压缩、工具编排、输出稳定性
