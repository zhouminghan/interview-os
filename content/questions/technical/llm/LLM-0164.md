出库任务自动化覆盖的链路是 **数仓表 → 出库服务 → 下游消费端（Kafka/Redis/API）**。

Skill 做的事情：
1. **生成出库配置**：根据用户指定的源表、目标系统、出库字段列表，自动生成出库任务配置文件（JSON 格式）。包括：源表分区策略、过滤条件、字段映射、序列化格式、目标 Topic/Key。
2. **依赖注册**：自动在调度系统里注册出库任务的上游依赖（哪个分区就绪后触发出库）。
3. **增量/全量策略**：根据出库目标自动选择——Kafka 通常走增量（每天新分区数据推送），Redis 走全量覆盖。
4. **自测验证**：生成后自动在测试环境执行一次，验证 Schema 兼容性和数据量级。

自动化程度：配置生成和依赖注册已经 100% 自动化。但首次上线需要 DE 确认配置正确性（P0 级审核）。迭代变更（比如加一个字段）走 P1 级，规则引擎校验后通知 DE 即可。
