# 一句话

对话/行为/反馈/埋点四类数据分别走埋点上报和日志流水接入 ODS，再统一清洗、去重、脱敏、结构化，沉淀到样本/特征层。

# 30 秒回答

对话数据解析成结构化（轮次/角色/内容），行为埋点做事件标准化，反馈做正负样本标注，埋点做口径统一。清洗：去重、低质过滤、脱敏、格式统一、按用户/会话关联。离线走 Spark 批处理，实时走 Flink。

# 1 分钟回答

- 接入：对话走流水，行为/埋点走 SDK 上报
- 清洗：去重、低质过滤、敏感脱敏、格式统一、多源关联
- 结构化：多轮对话按 session 建模，prompt/上下文/工具调用拆字段
- 分流：离线 Spark 批处理，实时 Flink + Kafka
- 用途：沉淀为样本层、特征层、评测数据
