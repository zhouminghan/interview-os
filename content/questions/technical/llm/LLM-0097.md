# 一句话

得物数仓侧 Harness 落地：五层防御体系解决 compact 失忆、规范不稳定、context 膨胀，八步标准流程把一次交付通过率从 50% 提到 90%。

# 30 秒回答

三大痛点：compact 失忆（压缩丢约束）、规范不稳定（靠 LLM 记忆仅 70~80%）、context 膨胀。五层防御：CLAUDE.md 持久化、Auto Memory 自动积累、Hooks 自动验证、Subagents 上下文隔离、SKILL 文件改造。Hooks 是核心，确定性执行 95%+。

# 1 分钟回答

- 五层：CLAUDE.md 持久化（compact 后约束不丢）、Auto Memory（跨会话口径沉淀）、Hooks（PostToolUse 检查 SQL 规范）、Subagents 隔离（血缘/自测/比对独立 context）、SKILL 改造（path-scoped 按需加载）
- Hooks：PostToolUse 查 SELECT * / PARTITION / DECIMAL / WHERE，PreToolUse 拦 DROP/TRUNCATE，SessionStart 重注入规范，Stop 查完整性
- 关键：阻断用 exit 2（exit 1 不阻止）
- 八步：需求分析→技术设计→ETL→自测→数据比对→SR 导入→性能优化→SLA
- 收益：效率 +30~50%，通过率 50%→90%，规范遵守 60~70%→95%+
