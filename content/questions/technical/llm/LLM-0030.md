# 一句话

LLM 是「大脑」，Agent 是「大脑 + 工具 + 记忆 + 规划 + 执行循环」。

# 30 秒回答

LLM 负责理解和生成；Agent 在 LLM 之上加工具调用、记忆、规划和执行循环，能自主完成多步任务。

# 1 分钟回答

- LLM：推理、生成、理解
- Agent：模型 + 工具 + 记忆 + 规划 + 循环
- 区别：Agent 能感知环境、行动、迭代
- 联系：LLM 是 Agent 的核心推理部件
