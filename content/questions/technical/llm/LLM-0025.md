# 一句话

自研更贴合业务、更可控、更轻，但成本高；成熟框架通用但重、不够贴合、依赖外部。

# 30 秒回答

成熟框架通用但重、不够贴合业务、可控性差；自研能针对业务定制流程、prompt、评测和权限，更轻更可控。选择看业务复杂度、可控性、维护成本和团队能力。

# 1 分钟回答

- 自研优势：贴合业务、可控、可定制流程和评测、无外部依赖
- 框架优势：开发快、生态全、省成本
- 权衡：业务复杂度、可控性、维护成本、团队能力
- 常见：框架复用通用能力 + 自研业务层
