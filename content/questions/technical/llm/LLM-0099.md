# 一句话

把数仓 SQL 库升级成 LLM 可查的代码知识库：每表一份「四件套」（DDL + 元数据 + 加工逻辑 + 调度依赖），支持表口径问答、取数 SQL 生成、口径迭代。

# 30 秒回答

每表一个文件夹，四件套：`ddl.sql`（字段 + COMMENT）、`metadata.yml`（中文名/业务含义）、`{表}.sql`（加工逻辑）、`{库}.{表}.yml`（调度依赖，含 parentTask 表级血缘）。LLM 靠这些做口径问答和 SQL 生成，不解析 SQL 也能拿血缘。

# 1 分钟回答

- 结构：`warehouse/{ods,dim,dwd,dws,ads}/{业务域}/{引擎}#{库}#{表}/`
- 四件套：DDL、metadata.yml、加工 SQL、调度 yml
- 血缘来源：yml 的 parentTask.dataName 现成，不用 AST 解析 SQL
- 方言：supersql（基于 Hive），含 `${YYYYMM}` 变量、`INSERT OVERWRITE ... PARTITION`
- 用途：表口径问答、取数 SQL 生成、口径/表状态迭代
- 维护：git 只读镜像，定时 pull + 重建更新
