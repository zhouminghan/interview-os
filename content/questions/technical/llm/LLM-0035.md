# 一句话

把传统四性校验 + LLM 的内容理解、跨模态检索、异常识别和质量筛选结合，做 Data Centric pipeline。

# 30 秒回答

传统校验（完整性/一致性/准确性/及时性/唯一性）打底，再用 LLM 做内容理解、跨模态检索、异常模式识别、质量筛选；校验规则作为 prompt，结合人工规则兜底。

# 1 分钟回答

- Data Centric：处理算子 + 跨模态检索 + 内容理解 + 质量筛选 + 组织合成
- 规则：完整性、唯一性、一致性
- LLM：异常识别、内容理解、质量打分
- 兜底：规则 + 模型 + 人工抽检
