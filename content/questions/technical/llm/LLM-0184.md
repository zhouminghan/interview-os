# 一句话

大头在 embedding 调用和向量库存储/查询，降本思路是批处理合并、缓存复用、冷热分层。

# 30 秒回答

embedding 最贵：批量合并请求、对没变化的文档缓存结果、用更小更省的模型。向量库其次：冷热分层，活跃向量放内存，冷数据落对象存储，按需降索引精度。清洗和分块 CPU 成本相对低，但也别重复跑，幂等 + 增量只处理变化的文档。

# 1 分钟回答

- embedding：批处理合并、缓存复用、小模型/量化
- 向量库：冷热分层、压缩索引（PQ）、控制副本数
- 存储：对象存储归档冷数据，生命周期清理
- 计算：增量处理 + 幂等，别全量重跑
- 监控：按环节拆成本，找占比最大的砍
- 原则：先砍用量，再降单价，再优化架构
