# 一句话

LLM 是大脑（只对话输出），Agent 是 LLM + 工具，Workflow 是把步骤固化的可复用流程。

# 30 秒回答

LLM 本身不能干活，Agent 靠 LLM + 工具（MCP/Skill）执行；Workflow 是把标准流程拆成固定步骤串起来，可复用、团队共享。
