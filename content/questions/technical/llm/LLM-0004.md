# 一句话

准确率看「执行结果是否一致」而不是「SQL 文本是否一致」；测试集用「问题 + 标准 SQL + 期望结果」标注。

# 30 秒回答

指标：结果集一致率、意图识别准确率、召回率。测试集覆盖真实业务问题 + 标准答案。两个 SQL 写法不同，要执行后比较结果集（schema + 数据）是否一致，再复核语义等价。

# 1 分钟回答

- 准确率：执行结果一致率（主）、SQL 文本精确匹配率（辅）、召回率
- 测试集：问题 + 标准 SQL + 期望结果，按主题/难度分层，持续补 badcase
- 判定：执行两个 SQL，比较结果集（列 + 行）是否相同，而非比较文本
- 原因：等价 SQL 可以有多种写法，文本一致会误判
