# 一句话

权限控制要覆盖「身份认证 -> 请求鉴权 -> SQL 校验 -> 数据行级/列级权限 -> 结果过滤 -> 审计」全链路。

# 30 秒回答

提交查询时先认证用户身份，鉴权能否访问该数据源，再校验生成的 SQL（表、字段、行级权限），执行后对结果做脱敏/过滤，全程审计留痕。

# 1 分钟回答

1. 认证：用户身份（登录态/API key）
2. 鉴权：是否有取数权限、可访问哪些数据源
3. SQL 校验：解析 SQL，校验表和字段权限、阻止越权查询
4. 行级/列级权限：按数据权限规则过滤
5. 结果处理：脱敏、限制返回量
6. 审计：记录查询请求、SQL、结果范围
- 大模型链路要防止 prompt 注入绕过权限，必须在引擎层做权限，不能只靠模型
