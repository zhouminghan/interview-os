# 一句话

按「采集 -> 消息 -> 实时/离线 -> 清洗去重 -> 多模态对齐 -> 数据集 -> 版本 -> 评测」设计闭环。

# 30 秒回答

对局日志/埋点/回放采集，经 Kafka 分实时流和离线批，清洗去重、多模态对齐、质量筛选，产出带版本的训练数据集，交付模型并回流评测。

# 1 分钟回答

- 采集：对局日志、操作/语音/画面埋点
- 传输：Kafka 分层（实时 + 离线）
- 处理：清洗、去重、对齐、筛选高质量
- 数据：多模态对齐、版本管理、特征
- 交付：训练集 + 评测集 + 反馈闭环

- 实时性和质量怎么平衡？
