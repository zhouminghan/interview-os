# 一句话

Flink SQL 实时强，Spark SQL 批处理生态好。

# 参考回答

Flink SQL 实时能力更强，事件时间、低延迟、exactly-once 是优势；Spark SQL 批处理和生态更成熟。流场景选 Flink，批场景两者都行。
