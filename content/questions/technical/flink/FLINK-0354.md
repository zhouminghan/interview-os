# 一句话

Blink 是阿里版 Flink，后来合并回社区。

# 参考回答

Blink SQL 是阿里基于 Flink 改进的版本，优化了流批一体、SQL 能力。后来 Blink 的很多特性合并回了 Apache Flink 社区版。现在说 Flink SQL 基本就是指合并后的版本。
