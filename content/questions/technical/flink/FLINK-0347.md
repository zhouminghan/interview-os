# 一句话

SQL Client 提交的作业能在 Web UI 看到。

# 参考回答

SQL Client 提交的作业会出现在 Flink Web UI，能看到作业状态、执行图、指标。两个配合用，SQL Client 写查询，Web UI 监控运行。
