difficulty: 0

许多现实行业的公司正在使用 Apache Flink，其用例如下：

- **金融服务**：金融行业使用 Flink 进行实时欺诈检测并发送移动通知。
- **医疗健康**：医院使用 Apache Flink 从 MRI、输液泵等设备收集数据，进行实时问题检测和分析。
- **广告技术**：广告公司使用 Flink 找出实时客户偏好。
- **石油天然气**：石油天然气行业使用 Flink 进行泵送的实时监控和问题检测。
- **电信**：电信公司使用 Apache Flink 为用户提供最佳服务，如账单和支付的实时视图、基于用户位置的天线优化、移动优惠等。
