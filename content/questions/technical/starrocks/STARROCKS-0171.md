# 一句话

用 MySQL 协议连，BI 工具当 MySQL 数据源接。

# 参考回答

BI 工具像 FineBI、Tableau、Superset，把 StarRocks 当 MySQL 数据源连接即可，因为协议兼容。选 StarRocks 的原因之一就是 BI 好接。
