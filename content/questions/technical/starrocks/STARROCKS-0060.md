# 一句话

提 issue、改文档、修 bug、提 PR 都能贡献。

# 参考回答

参与方式从轻到重：提交 issue 反馈 bug 或需求、改进文档、认领 good first issue、提交 PR 修 bug 加功能。一般先看贡献指南，跟着社区规范来。
