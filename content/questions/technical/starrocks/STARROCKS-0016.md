# 一句话

StarRocks 是一个开源的 MPP 架构列式分析型数据库，主打极速多维分析。

# 参考回答

StarRocks 是新一代的 OLAP 数据库，MPP 架构、列式存储加向量化执行，主打海量数据的实时分析。它兼容 MySQL 协议，能直接当 BI 的查询引擎用，做报表、大屏、实时数仓都行。
