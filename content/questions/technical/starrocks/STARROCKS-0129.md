# 一句话

两者同源，StarRocks 从 Doris 分支出来，架构相似。

# 参考回答

StarRocks 和 Doris 同源，都是 MPP 加列存，很多设计类似。StarRocks 从 Doris 早期版本分叉出来独立发展，后续在性能、主键模型、存算分离上有自己的路线。面试说清同源加各自演进就行。
