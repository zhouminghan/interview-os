# 回答思路

1. 开口先说快排的核心是 partition：选一个基准值，把数组按大小拆开，而不是先背复杂度。
2. 接着讲递归：对小于和大于基准值的两段继续排序，等于基准值的部分放在中间。
3. 然后推导复杂度：分区每层处理 O(n) 个元素，递归深度决定总时间和栈空间。
4. 最后补工程边界：pivot 选择、重复元素、最坏情况和不稳定性都要交代。

# 一句话

快速排序通过选 pivot 做分区并递归排序两侧，平均时间 O(n log n)、最坏 O(n²)，平均递归栈 O(log n)，原地分区但不稳定。

# 30 秒回答

我会先讲一次分区怎么做：选一个基准值，把比它小的放左边、比它大的放右边，等于它的集中在中间，然后只对左右两段递归。每层总共扫一遍元素，所以时间主要看递归深度。划分比较均衡时深度是 log n，平均复杂度就是 O(n log n)；如果每次都极不平衡，就会退化到 O(n²)。实现里常用随机 pivot 降低撞上最坏情况的概率。

# 1 分钟回答

第一，讲算法与空间：原地分区只需要常数级辅助变量，但递归调用栈平均是 O(log n)，最坏可到 O(n)；优先递归较小区间并把较大区间改成循环，可以把栈空间压到 O(log n) 量级。第二，讲复杂度边界：固定取首/尾元素时，已排序或逆序数组容易每次得到 0 和 n-1 的划分，递推变成 T(n)=T(n-1)+O(n)，即 O(n²)；随机 pivot 或三数取中只是降低概率，不会给出绝对保证。第三，讲落地：大量重复值用三路分区，避免相等元素反复递归；需要最坏 O(n log n) 时可用 introsort，在递归过深时切换堆排序；快排不是稳定排序，若相等元素的原始顺序有业务含义，应选归并排序或给元素附原下标。

# 追问

- 最坏情况什么时候出现？回答要点：每次 pivot 都把数组划成 0 和 n-1 两段，例如固定选端点且输入已有序，递归深度变为 n，总时间为 O(n²)。
- 随机 pivot 能彻底避免最坏情况吗？回答要点：不能，只能显著降低特定输入触发极端划分的概率；结合三数取中、三路分区，必要时用 introsort 的堆排序兜底。
- 快排的空间复杂度和稳定性如何？回答要点：原地分区但递归栈平均 O(log n)、最坏 O(n)；分区交换会改变相等元素相对顺序，因此不是稳定排序。
