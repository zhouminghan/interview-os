## 量化证据

- 问题库 DOM 实测 3169 个 `.q-row`；探索页 80 个 `.ex-item`；面经页 850 个 `.ex-item`；系统图解页 110 个 `.ex-item`。
- 390px iframe 测量：7 个页面 `documentElement.scrollWidth` 均为 390，没有整页横向滚动；唯一明显裁切是 `.nav-links`（client 87 / scroll 382 / over 295，`overflow-x:auto`）。顶层截图另有 `.q-row`、`.chips`、`.rank-row` 右侧文字被裁，需以顶层截图为最终验收。
- 按 AGENTS 规定的「一句话 / 30 秒回答 / 1 分钟回答 / 追问」四段结构，2809 张题卡缺至少一段；1097 个 section 无标题；1458 张整题正文不足 120 字；18 张技术题卡正文不足 30 字或只有空壳「答案要点」。
- 章节标题混入「你的原回答评价」「本题评分」「如果我是求职者，我会这样回答」「最终记忆版」等 21 处 AI 教练口吻；大量「追问」只有问题、没有回答要点。
- 27 张 `source_type: knowledge` 题卡带 `sources` 绑定面经，违反「八股不写 sources」。行为题抽查未发现虚构经历，`needs_personal_input: true` 的 105 张框架卡合规。
- 23 篇面经被解析成 0 items；123 篇没有关联题卡；仅 10 张题卡含图。

## 剩余可执行方案

### P1：下一轮必须做

- 内容治理：把 1458 张正文不足 120 字的题卡按「高频 / 面经来源 / 空壳」三档排队；每档先补「回答思路 + 30 秒口语段落 + 追问回答要点」，不要一次铺长篇教程。验收：`<120 字` 数量下降 50%，高频题卡 100% 有追问要点。
- AI 教练口吻清理：21 张含「你的原回答评价 / 本题评分 / 如果我是求职者」的题卡，隐藏或改写为中性章节；`stage_key: coach` 的内容在训练态默认折叠，只在复盘态显示。验收：问题库与训练答案里不出现评分/背熟/求职者视角文案。
- 掌握度统一：当前 `os.practice.log` 只有 会/模糊/不会，`os.explore` 另有 0-5 掌握度，两者隔离；按 AGENTS 第 11 节统一为 0-5 且技术题分 knowledge / expression / project / follow_up，行为题分 content / expression / structure / risk。验收：一次评分同时写入练习记录与题卡掌握度，画像能按维度展示。
- 面经反哺：123 篇无关联题卡，建立 `interview_id -> question_id` 反向索引与半自动相似匹配；面经逐题右栏优先展示「本题最佳匹配 + 次优候选」，而不是当前 bigram 阈值 0.28 的单条猜测。验收：面经页不再大面积显示「还没有沉淀题卡」。
- 训练闭环：新增错题本与复习队列，按「最近一次 grade<2 / 看过答案 / 距离上次复习天数」排序；支持只练未掌握维度，而不只是只练薄弱题。验收：从画像薄弱项可一键开始定向训练。
- 反馈机制：标记掌握、切换主题、清空训练记录、显示更多、揭示答案都给轻量内联反馈或可撤销；全局搜索支持上下键、回车、Esc 与空结果建议。验收：所有改变状态的操作在 1 秒内有可见反馈。

### P2：体验打磨

- 问题库增加排序（频率 / 难度 / 最近练习 / 掌握度）、多选批量加入训练、最近访问；面经侧栏按公司或月份分组；系统图解 12 个系统加搜索与完成进度。
- 长题卡答案增加阶段目录与回到顶部；图表节点加 `role="img"` 与 `aria-label`；表格补 `table` / `th` / `td` 样式，当前 `build.py` 会生成表格但 CSS 没有对应规则。
- 统一组件语义：`.rank` 只用于真实榜单，列表序号用独立中性样式；速度控制从 `.chip` 拆成独立 stepper；所有图标按钮补 tooltip 与稳定 36x36 尺寸；统一 `.q-detail` / `.wiki-doc` / `.ex-main` 的内边距与标题层级。
- 更新 `README.md` 页面清单为 7 个，更新 `docs/content-schema.md` 记录 `stage_key` / `stage_label` / `answer_outline` / `kind` 字段；统一命名「交互式学习」与「探索」。
- 视觉：在保持现有设计系统的前提下，给成功、警告、来源、待补个人事实建立稳定的语义色，而不是继续用橙色承担所有强调；检查深色模式正文对比度与长文行高。

### P3：长期

- 零构建约束下评估 `data.js` 分片或按需解析：当前单文件 122925 行、3169 题全量注入内存；任何拆分都必须保持 `file://` 离线可用，不引入打包器。
- 把构建期校验做成提交前钩子或 CI 检查：重复 ID、非法 ID、source_type 越界、空壳答案、0 题面经、虚构经历关键词抽检。
- 定期抽检 `needs_personal_input: true` 的行为题，确保只搭框架、不填虚构个人事实；AI 生成追问与面试官原话始终分开标注。
