# Interview OS

个人面试知识库与训练系统。以真实面经为输入，沉淀为结构化 QA，再用随机测试和表达训练把知识变成面试能力。

## 定位

不是「面经收藏夹」，而是：

面经 -> AI 结构化 -> QA / 知识沉淀 -> 主动训练 -> 薄弱点反馈 -> 再复习

## 三类内容

- **Technical QA**：有标准答案的技术题（正确性 + 表达 + 追问 + 项目结合）
- **Behavioral / HR**：重表达、立场与信息组织的开放题
- **Negotiation**：谈薪与谈判筹码

## 技术栈（MVP）

- 内容源：Markdown / YAML
- 展示：静态站点，零构建，vanilla JS + CSS
- 训练状态：浏览器 LocalStorage
- 部署：GitHub Pages
